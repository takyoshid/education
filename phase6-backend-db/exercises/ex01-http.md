## 難易度 2: 設計問題

### 問題 2-1: REST API の設計

「ブログ投稿管理システム」の REST API を設計してください。次の要件を満たすこと。

**リソース:**
- ユーザー(User)
- 投稿(Post)
- コメント(Comment)

**要件:**
1. ユーザーの CRUD(作成・取得・更新・削除)
2. 投稿の CRUD
3. 特定ユーザーの投稿一覧を取得
4. 投稿に対するコメントの追加と一覧取得
5. 投稿の検索(タイトルのキーワード検索)
6. 投稿をページネーション(1 ページ 10 件)で取得

以下の形式で回答してください：

```
メソッド  URL                                  説明
GET      /...                                 ...
POST     /...                                 ...
```

### 問題 2-2: リクエスト・レスポンスの設計

問題 2-1 の「投稿を作成する」エンドポイントについて、以下を設計してください。

1. リクエストボディ(JSON)
2. 成功時のレスポンスボディ(JSON)とステータスコード
3. バリデーションエラー時のレスポンス(タイトルが空だった場合)
4. 認証エラー時のレスポンス

### 問題 3-2: curl コマンドの作成

以下の要件を満たす curl コマンドを書いてください。

**前提:** ベース URL は `http://localhost:8000/api/v1`

1. ユーザー一覧を取得する
2. 以下のデータで新規ユーザーを作成する

   - email: "tanaka@example.com"
   - password: "SecretPass1"
3. JWT トークン `eyJ...` を Authorization ヘッダーに付けて、自分のプロフィールを取得する
4. ユーザー ID 42 のメールアドレスだけを "new@example.com" に更新する
