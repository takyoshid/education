# Lesson 06: 海外就職・リモート就職の実際

## はじめに

「海外で働く」というと、ビザの壁が高そうに見えますが、リモートワークの普及によりその選択肢は大きく広がっています。「海外に移住しなくても、海外企業でリモートワークする」という形が現実的になっています。

このレッスンでは、現実的な選択肢・給与相場・応募戦略を解説します。

---

## 1. 日本在住エンジニアの選択肢

### 選択肢 A: 完全リモート(日本在住のまま)

最も現実的な第一歩です。日本に住みながら、海外企業(主に米国・欧州)でフルリモートで働きます。

**メリット:**
- ビザ不要
- 日本の生活コストのまま、海外給与を受け取れる
- 時差さえ管理できれば今すぐ始められる

**デメリット:**
- 時差の問題(米国東海岸は 13〜14 時間差)
- 「日本時間での契約」が求められる場合もある
- 一部の企業は特定の国への支払いに制限がある

**向いている企業:**
- リモートファースト企業(後述)
- 欧州の企業(時差が少ない)
- Contractor(業務委託)として雇用するスタートアップ

### 選択肢 B: 海外移住して就労

ビザを取って現地で働く形。難易度は上がりますが、長期的なキャリアと報酬を考えると最も有利です。

**主な移住先と難易度:**

| 国 | ビザの種類 | 難易度 | 特徴 |
|----|---------|-------|------|
| アメリカ | H-1B ビザ | 高い(抽選) | 最高の給与水準。抽選なので不確実 |
| カナダ | Express Entry | 中程度 | IT 系は優遇。ポイント制で予測しやすい |
| ドイツ | EU Blue Card | 中程度 | 高い給与基準が必要。欧州への足がかり |
| オランダ | Highly Skilled Migrant | 中程度 | 英語が通じやすい。欧州最大のエンジニア市場の一つ |
| オーストラリア | Employer Sponsored (482) | 中程度 | 時差が少ない、生活しやすい |
| シンガポール | Employment Pass | 中程度 | アジア最大の金融・テックハブ |
| UAE(ドバイ) | Golden Visa | 低〜中 | 税制優遇。個人所得税ゼロ |

### 選択肢 C: 外資系日本法人

日本に拠点がある外資系企業(Google, Amazon, Microsoft, Stripe など)の日本オフィスで働く方法。英語での作業が多く、海外チームと働くキャリアのステップとして有効です。

## 2. 給与相場

### 米国(シリコンバレー・リモート)のエンジニア給与

以下は 2024〜2025 年時点の目安です。"TC" は Total Compensation(給与+株+ボーナスの合計)を意味します。

| レベル | ポジション | Base Salary | TC (Total Comp) |
|-------|----------|------------|-----------------|
| Entry | L3 / Software Engineer I | $130,000〜$160,000 | $170,000〜$250,000 |
| Mid | L4 / Software Engineer II | $160,000〜$200,000 | $250,000〜$400,000 |
| Senior | L5 / Senior Engineer | $190,000〜$250,000 | $350,000〜$600,000 |
| Staff | L6 / Staff Engineer | $230,000〜$300,000 | $500,000〜$1,000,000+ |

注: FAANG(Google, Amazon, Apple, Netflix, Meta)はこれより高く、スタートアップはこれより低い傾向があります。

### 欧州のエンジニア給与(ベルリン・ロンドン・アムステルダム)

米国より低いですが、社会保障・有給日数・ワークライフバランスが優れています。

| レベル | ベルリン | ロンドン |
|-------|---------|--------|
| Junior | €50,000〜€65,000 | £45,000〜£60,000 |
| Mid | €65,000〜€90,000 | £60,000〜£85,000 |
| Senior | €90,000〜€130,000 | £85,000〜£130,000 |

### リモート給与の参考サイト

- levels.fyi — 企業別・レベル別の実際の給与データ
- glassdoor.com — 求人と給与の口コミ
- blind app — エンジニアの匿名コミュニティ(給与交渉に有益)
- remoteok.com — リモート求人と給与帯

## 4. 応募戦略

### 量より質

やみくもに 100 社に応募するより、20 社に丁寧に応募する方が成果が出ます。

**ターゲット企業リストの作り方:**
1. 使っている技術スタックが自分の強みと一致するか
2. 会社の成長フェーズ(スタートアップ vs. 大企業 — それぞれ求めるスキルが違う)
3. プロダクトが自分にとって面白いか(モチベーションが面接で伝わる)
4. 給与レンジが自分の期待に近いか(Glassdoor, levels.fyi で確認)

### 応募の優先順位付け

```
ドリームカンパニー (10 社)
  → ここに受かりたい。準備に最も時間をかける

ターゲットカンパニー (20 社)
  → 現実的に受かる可能性が高い。メインの応募先

バックアップ (10 社)
  → 確実に受かると思う企業。練習兼保険
```

### リファラル(紹介)の重要性

統計的に、リファラルによる応募は書類通過率が 5〜10 倍高いです。

**リファラルを得る方法:**
1. LinkedIn でターゲット企業に勤めている日本人エンジニアを探す
2. カジュアルな質問から始める(「その企業での働き方について聞かせていただけますか?」)
3. 繋がりができたら、リファラルをお願いする

**メッセージの例:**
```
Hi Yuki,

I'm a software engineer based in Tokyo with 4 years of experience in
React and Node.js. I'm really excited about Stripe's developer-first
approach and have been using the API for about 2 years.

I'm interested in applying for the Software Engineer role on the
Payments team. Would you be willing to have a quick 20-minute call
to learn more about your experience there? Any insights you could
share would be greatly appreciated.

Thanks!
Takuya
```

### カバーレターの要否

「カバーレターは読まれない」と言う人もいますが、特にスタートアップでは読まれます。

書く場合のポイント:
- 「なぜこの会社か」を具体的に書く(プロダクトを使ったことがある、創業者の考えに共感した、など)
- 3〜4 段落以内に収める
- 自分の最も強い実績を 1 つ具体的に書く

## 5. 応募後のプロセス

典型的な採用フロー:

```
1. 書類選考 (1〜2週間)
   ↓
2. 採用担当者との電話スクリーニング (30分)
   → カルチャーフィット、基本的な経験確認
   ↓
3. 技術スクリーニング (30〜45分)
   → コーディング問題 1〜2問 (LeetCode 系)
   ↓
4. オンサイト/バーチャル面接ループ (4〜5時間)
   → コーディング × 2〜3
   → システム設計 × 1
   → 行動面接 × 1〜2
   ↓
5. オファー (1〜2週間後)
   ↓
6. 交渉 → 入社
```

---

## まとめ

- リモートワークにより、日本在住のまま海外企業で働くことが現実的になった
- 米国の給与水準は日本の数倍だが、欧州でも日本より高い
- リモートファースト企業への応募には Remote OK, We Work Remotely を使う
- リファラルは書類通過率を大幅に上げる。LinkedIn での繋がりを積極的に作る
- 応募は量より質。ターゲットを絞って丁寧に準備する
