# LinkedIn プロフィール 書き方ガイド

---

## このガイドについて

LinkedIn はグローバル転職活動において最も重要なプラットフォームの一つです。北米・欧州・シンガポールの採用担当者の多くは、履歴書を受け取る前に LinkedIn でプロフィールを確認します。

このガイドでは、ソフトウェアエンジニアとして海外・グローバル企業への転職を目指す際に特に重要な各欄の書き方を、英文例と日本語訳のセットで解説します。

---

## プロフィール写真 (Profile Photo)

採用担当者がプロフィールを見たときに最初に目に入る要素です。

**良い写真の条件:**
- 顔がはっきり見える、明るい照明の写真
- 背景がシンプル(白壁・ぼかし背景など)
- ビジネスカジュアル以上の服装
- 正面または少し斜めから撮影
- 最近3年以内に撮影したもの

**避けるべき写真:**
- 全身写真・友人と写った写真を切り抜いたもの
- サングラス・帽子をかぶった写真
- 解像度が低い・暗い写真

## Headline (見出し)

プロフィール写真の下に表示される1行のテキスト。LinkedIn の検索結果にも表示されるため、キーワードを意識して書く。

**デフォルトを使わない:** LinkedIn は自動的に「Software Engineer at 〇〇 Company」と入力するが、これは最低限の情報しか伝わらない。

### フォーマットのパターン

**パターン1: 役割 + 技術 + 専門性**
```
Backend Software Engineer | Go, Kubernetes | Distributed Systems
```

**パターン2: 役割 + 価値提供**
```
Senior Full-Stack Engineer | Building Products for Global Users | TypeScript, AWS
```

**パターン3: 役割 + 目指すもの(転職活動中の場合)**
```
Software Engineer | 5 Years in FinTech & E-Commerce | Open to Global Opportunities
```

### 記入例と解説

```
Backend Engineer at Mercari | Go, PostgreSQL, Kafka | Scalable Systems & API Design
```

日本語訳:
```
// メルカリのバックエンドエンジニア | Go、PostgreSQL、Kafka | スケーラブルシステムとAPI設計
```

良い理由:
- 現在の所属がある(信頼性)
- 使っている技術がある(検索でヒットする)
- 専門性・興味が分かる
- 220文字以内に収まっている

## About (自己紹介文)

最大2,000文字。採用担当者が「この人と話してみたい」と思うかどうかを左右する重要なセクション。レジュメの Summary よりも人間的な文体で書いてよい。

### 構成の型

```
段落1: 何者か・何が得意か(2〜3文)
段落2: どんな問題・領域に情熱があるか(2〜3文)
段落3: 具体的な実績や取り組み(2〜4文)
段落4: 今何を探しているか・どんな人と話したいか(1〜2文)
```

### 記入例

```
I'm a backend software engineer with 5 years of experience building
distributed systems and developer tools at Japanese tech companies.
I specialize in Go and TypeScript and am most comfortable working on
the intersection of reliability engineering and product development.

I'm particularly drawn to problems where scale and correctness both matter —
systems that need to be fast, fault-tolerant, and easy for other engineers
to reason about. I believe that good software is as much about the developer
experience of maintaining it as it is about the end-user experience of using it.

At Mercari, I led the architecture of a real-time notification system processing
500,000 events per day, and reduced our core API latency by 80% through
Elasticsearch optimization. More recently, I've been building internal tooling
to help 200+ engineers deploy and monitor services safely.

I'm currently exploring senior and staff engineer roles at global product
companies — especially those working in platform engineering, developer
tooling, or high-scale consumer applications. If you're working on something
interesting in that space, I'd love to connect.
```

日本語訳:
```
// 私は日本のテック企業で5年間、分散システムと開発者ツールを構築してきた
// バックエンドソフトウェアエンジニアです。Go と TypeScript を専門とし、
// 信頼性エンジニアリングとプロダクト開発の交差点での仕事が得意です。
//
// 特に、スケールと正確性の両方が重要な問題に引きつけられます — 高速で、
// フォールトトレラントで、他のエンジニアが理解しやすいシステムです。
// 優れたソフトウェアとは、エンドユーザー体験と同様に、保守する開発者体験も
// 重要だと信じています。
//
// メルカリでは、1日50万イベントを処理するリアルタイム通知システムのアーキテクチャをリードし、
// Elasticsearch の最適化でコア API レイテンシを80%削減しました。最近は200名以上の
// エンジニアが安全にサービスをデプロイ・監視できる内部ツールを構築しています。
//
// 現在、グローバルなプロダクト企業でのシニア/スタッフエンジニアの役割を探しています —
// 特にプラットフォームエンジニアリング、開発者ツール、高スケールなコンシューマーアプリに
// 取り組んでいる企業。その分野で興味深いことに取り組んでいる方と繋がりたいです。
```

**書くときのポイント:**
- 「I'm passionate about...」は多用されすぎて陳腐化している。何が好きかではなく、何に引きつけられるか・なぜそれが重要かを書く
- 最後の段落で「今探しているもの」を書くことで、採用担当者が声をかけやすくなる
- 箇条書きは使わない。文章で書くことで「人らしさ」が出る

## Experience (職歴)

レジュメの職歴セクションと同じ内容を基本としてよいが、LinkedIn は文字数の制限が緩く、より文章的に書くことができる。

### フォーマット

各ポジションに以下を書く:
1. **最初の1〜2文:** このポジションで何をしたか・何に責任を持ったかの概要
2. **箇条書きまたは段落:** 具体的な実績(数値付き)
3. **最後の1文(任意):** このポジションで最も学んだことまたは成長したこと

### 記入例

**会社名:** Example Tech
**役職:** Software Engineer
**期間:** June 2021 – Present

```
I joined Example Tech as a backend engineer on the Platform team,
responsible for the core infrastructure services used by all product teams.

Key contributions:
- Architected and shipped a real-time event processing pipeline handling
  500,000 events/day using Go, Kafka, and Redis, cutting notification
  latency from 8 seconds to under 200ms.
- Led a zero-downtime PostgreSQL migration for our primary user table
  (12M rows), executing a dual-write strategy over a 3-week period.
- Mentored 2 junior engineers; both received strong performance ratings
  in their first annual review.
- Reduced AWS costs by 38% (~$2,400/month) by right-sizing instances
  and moving batch workloads to Lambda.

This role deepened my understanding of large-scale systems and taught me
how to communicate technical trade-offs to non-technical stakeholders.
```

日本語訳:
```
// Example Tech にプラットフォームチームのバックエンドエンジニアとして入社し、
// すべてのプロダクトチームが使うコアインフラサービスを担当しました。
//
// 主な貢献:
// - Go、Kafka、Redis を使い1日50万イベントを処理するリアルタイムイベント処理パイプラインを
//   設計・リリース。通知レイテンシを8秒から200ms未満に削減。
// - メインユーザーテーブル(1,200万行)のゼロダウンタイム PostgreSQL マイグレーションをリード。
//   3週間にわたるデュアルライト戦略を実施。
// - 2名のジュニアエンジニアをメンタリング。両者とも初年度レビューで高評価。
// - インスタンスの適正サイズ化とバッチ処理の Lambda 移行で AWS コストを38%削減(月約24万円)。
//
// このポジションで大規模システムへの理解が深まり、技術的なトレードオフを
// 非技術系ステークホルダーに伝える方法を学びました。
```

## Skills (スキル)

LinkedIn の Skills セクションには最大50個のスキルを登録できる。上位3つが特に目立つ表示になるため、最も重要なスキルをトップ3に設定する。

### 推奨スキルの選び方

**優先度の高いスキル:**
- 応募したいポジションの Job Description に頻繁に登場するもの
- 実務での使用経験が豊富なもの
- 技術スクリーニングで問われそうなもの

**追加しない方が良いもの:**
- 使ったことはあるが業務レベルではないもの
- Microsoft Office・PowerPoint のような汎用ツール
- 「Leadership」「Communication」のような曖昧なソフトスキル

### スキル例(バックエンドエンジニアの場合)

上位3つ(目立つ位置に表示):
```
1. Go (Programming Language)
2. System Design
3. PostgreSQL
```

その他のスキル:
```
TypeScript, Node.js, Kafka, Redis, Kubernetes, Docker,
AWS, Terraform, REST APIs, Microservices, SQL, Python,
Technical Leadership, Code Review
```

## Recommendations (推薦文)

採用担当者が信頼性の指標として確認するセクション。1〜3件あると良い。

### 誰に依頼するか

- 直属のマネージャー
- 密接に協力した同僚エンジニア
- メンタリングしたジュニアエンジニア

### 依頼するときのメッセージ例

```
Subject: LinkedIn Recommendation Request

Hi [Name],

I hope you're doing well. I'm updating my LinkedIn profile and exploring
new opportunities, and I was wondering if you'd be willing to write a
short recommendation for me.

If you're open to it, it would mean a lot if you could speak to
[specific project] or [specific aspect of your work together]. Of course,
I'm happy to return the favor whenever you need it.

No pressure at all — I completely understand if you're busy.

Thanks,
Takuya
```

日本語訳:
```
// 件名: LinkedIn 推薦文のお願い
//
// [名前]さん、
// お元気でしょうか。LinkedIn プロフィールを更新して新しい機会を探しているのですが、
// 短い推薦文を書いていただけないでしょうか。
//
// もし可能であれば、[特定のプロジェクト] または [協力した特定の側面] について
// 書いていただけると非常に助かります。もちろん、必要なときはいつでもお返しします。
//
// プレッシャーをかけるつもりは全くありません — お忙しい場合は十分理解できます。
//
// よろしくお願いします。
// 吉田
```

## オープン・トゥ・ワーク (Open to Work) の設定

転職活動中であることを採用担当者にのみ表示する設定が可能。現在の職場に知られたくない場合は「Recruiters only」オプションを選択する。

### 設定項目の書き方例

**Job titles:**
```
Senior Software Engineer
Staff Engineer
Backend Engineer
Platform Engineer
```

**Job types:**
```
Full-time
```

**Locations:**
```
Remote
San Francisco Bay Area, CA
Singapore
Tokyo, Japan
```

**Start date:**
```
Immediately (すぐ転職可能)
3 months (3ヶ月以内)
```

## プロフィール完成度チェックリスト

LinkedIn は「Profile Completeness」を内部スコアとして持ち、スコアが高いプロフィールは検索結果の上位に表示されやすい。

- [ ] プロフィール写真を設定した
- [ ] Headline を職種 + 技術 + 専門性の形式で書いた
- [ ] About セクションを300文字以上書いた
- [ ] 現在を含む直近3ポジションの Experience を記入した
- [ ] 各 Experience に具体的な実績を3件以上書いた
- [ ] Education セクションを入力した
- [ ] Skills を10個以上登録した
- [ ] 少なくとも1件の Recommendation を受け取った
- [ ] GitHub・個人ウェブサイトのリンクを Contact Info に追加した
- [ ] プロフィールの言語が英語に設定されている(英語圏向けの場合)

## 採用担当者からのメッセージへの返信例

LinkedIn で採用担当者からスカウトメッセージが来たときの返信例。

### 興味がある場合

```
Hi [Recruiter Name],

Thank you for reaching out. I'm familiar with [Company Name] and I've
been following your work on [product/area].

I'd be happy to have a conversation. Could you share more details about
the role — specifically the team, the technical challenges they're
working on, and the expected level of seniority?

Looking forward to hearing more.

Best,
Takuya
```

日本語訳:
```
// [採用担当者名]さん、
// ご連絡ありがとうございます。[会社名]は知っており、[製品・分野]での取り組みをフォローしています。
// ぜひ話してみたいです。役割について詳しく教えていただけますか — 特にチーム、
// 取り組んでいる技術的な課題、期待されるシニアリティについて知りたいです。
// 詳細をお待ちしています。
```

### 興味がない場合

```
Hi [Recruiter Name],

Thank you for reaching out. I appreciate you thinking of me, but I'm
not currently looking for opportunities at [Company Name] / in [industry].

I'll keep you in mind if that changes. Best of luck with the search.

Best,
Takuya
```

日本語訳:
```
// [採用担当者名]さん、
// ご連絡ありがとうございます。ご検討いただき感謝します。しかし現在、
// [会社名] / [業界] での機会は探していません。
// 状況が変わったときはご連絡します。採用活動がうまくいくことを願っています。
```
