対応レッスン: Lesson 05「英文レジュメと LinkedIn」

---

## この演習について

英文レジュメの中で最も差がつくセクション「Work Experience」の実績記述を STAR 形式で書く練習をします。日本語の職務経歴書に書いてある内容を、英語の成果型記述に変換することが目標です。

所要時間の目安: 90〜120 分

---

## STAR 形式の復習

レジュメの実績記述では、STAR の S(Situation)と T(Task)は暗黙の前提として省略し、A(Action)と R(Result)を1〜2文に凝縮します。

```
パターン: [Action Verb] + [具体的な行動] + [数値を含む成果]
```

例:
```
Reduced API response time by 40% by implementing Redis caching across
the 3 most frequently accessed endpoints, improving user retention by 12%.

// 最も頻繁にアクセスされる3つのエンドポイントにRedisキャッシュを実装し、
// APIレスポンスタイムを40%削減し、ユーザーリテンションを12%改善した。
```

---

## 学習のヒント

- アクション動詞のバリエーションを増やす: Architected, Engineered, Spearheaded, Streamlined など
- 数値がない場合も諦めない: "significantly", "dramatically", "across the entire team" などで具体性を補える
- 同じ動詞を繰り返さない。5つの箇条書きで "developed" を3回使わない
- Professional Summary は求人票を読んでから書く。キーワードを合わせると ATS 通過率が上がる
- `templates/resume-template.md` のテンプレートに自分の情報を入れてレジュメ全体を完成させる
