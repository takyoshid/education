# Phase 10: 英語とグローバルキャリア

## この Phase について

Phase 10 は、世界で通用するエンジニアになるための英語力とキャリア戦略を体系的に学ぶフェーズです。

**重要: Phase 2 開始時から並行して継続してください。**

他のフェーズでコードを書きながら、このフェーズの学習を毎日少しずつ積み重ねることが最も効果的な学習方法です。英語は短期集中よりも長期継続が成果を生みます。毎日30分でも英語に触れる習慣を作ることが最優先です。

---

## 🌟 旅の始まりに: 「彼女が良いと言うなら、私は飛ぶ」

1962年、アメリカ初の有人地球周回飛行の直前。宇宙飛行士ジョン・グレンは、最新の IBM コンピュータが弾き出した軌道計算を前に、こう要求しました。

> 「**あの女性に数字を確認させてくれ。彼女が『良い』と言うなら、私は飛ぶ。**」

「あの女性」とは NASA の計算手**キャサリン・ジョンソン**。人種隔離が残る1960年代のアメリカで、黒人女性として働く数学者でした。当時の彼女を取り巻く壁は、想像を絶するものです。それでも、軌道計算の正確さで積み上げた信頼は、宇宙飛行士が自分の命を預ける相手として彼女を名指しさせるほど絶対的でした。彼女は手回し計算機で全軌道を検算し、グレンは飛び、無事に帰還しました(この物語は映画『ドリーム(Hidden Figures)』になり、彼女は大統領自由勲章を受けています)。

グローバルキャリアの本質は、これです。**実力で築いた信頼は、言語・国籍・出自、どんな壁も越える。** この Phase で磨く英語は、その信頼を伝えるための配管にすぎません。中を流れるもの — ここまで11フェーズかけて積んだ実力 — を、あなたはもう持っています。

## 学習目標

### 英語力
- 英語の技術ドキュメント・Issue・PR を辞書なしで読めるようになる
- 自然なコミットメッセージ・PR 説明・Issue 報告を英語で書けるようになる
- スタンドアップや 1on1 などの日常的な業務会話を英語でこなせるようになる
- 技術的な設計議論に英語で参加できるようになる

### キャリア
- 世界標準の英文レジュメと LinkedIn プロフィールを完成させる
- 海外企業・リモートファースト企業への応募戦略を立てられるようになる
- コーディング面接・行動面接・システム設計面接を英語でパスできるようになる
- オファーを受けた後の交渉と入社後の立ち上がりを計画できるようになる

## 修了条件チェックリスト

以下をすべて達成したとき、このフェーズを修了とします。

### 英語基礎
- [ ] 英語の公式ドキュメント(MDN, AWS, GitHub Docs など)を辞書なしで読み進められる
- [ ] 英語のコミットメッセージを毎回書けている(日本語コミットが 0 件)
- [ ] GitHub の Issue または PR を英語でオープンした経験が 3 件以上ある
- [ ] 英語の技術系ポッドキャストまたは YouTube を週 3 回以上聴いている

### アウトプット
- [ ] 英文レジュメ(1〜2ページ)を完成させた
- [ ] LinkedIn プロフィールを英語で完成させ、「Open to Work」または「Open to Opportunities」を設定した
- [ ] カバーレターの雛形を 1 本書いた
- [ ] 英語で自己紹介(2分間)を暗記して話せる

### 面接準備
- [ ] コーディング面接の think aloud スクリプトを使って、LeetCode Easy 問題を英語で解いた(5問以上)
- [ ] STAR 形式の回答を 5 問以上準備した
- [ ] システム設計面接のウォークスルー(URL 短縮サービス)を声に出して通しで練習した
- [ ] 模擬面接を 1 回以上(友人・Pramp・interviewing.io 等)受けた

### 応募活動
- [ ] ターゲット企業リストを 10 社以上作成した
- [ ] 実際に 3 社以上に応募した
- [ ] オファーを 1 件以上受けた場合、給与交渉のスクリプトを使って交渉を試みた

## 推奨学習ペース

| タイミング | やること |
|-----------|---------|
| 毎朝 10 分 | 英語の技術記事を 1 本読む(DEV.to, Medium, Hacker News) |
| 毎日のコーディング中 | コミットメッセージ・変数名・コメントを英語で書く |
| 週 2 回 30 分 | レッスンを 1 つ進める + 演習を解く |
| 週 1 回 1 時間 | 模擬面接の練習(一人でもよい、声に出して行う) |
| 月 1 回 | レジュメ・LinkedIn を更新する |
