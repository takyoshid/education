# 永久層 — 変化しても使い続ける6つの力

この層は、プログラミングを始める前に学び、その後のすべてのPhaseで使い続けます。
特定の言語、製品、職業の知識ではありません。未知の状況に出会ったときに、自分と他者の知恵を使って前へ進むための基礎です。

「永久」とは、ここに書かれた答えが永久に正しいという意味ではありません。**答えや教材そのものを疑い、証拠によって更新する方法が長く使える**という意味です。

## 対象

本編と同じく、**高校生以上、または同等の読解力を持つ学習者**を想定しています。
年齢ではなく、次のことができるかを目安にしてください。

- 1,000〜2,000字程度の説明を読み、要点を自分の言葉で話せる
- 分からない言葉を調べながら読み進められる
- 30分程度、一つの問いについて考えたり試したりできる
- 保護者や先生、学習仲間に考えを説明できる

## 6つの力

| # | 領域 | 中心となる問い |
|---|---|---|
| 1 | [問いを作る](lessons/01-making-questions.md) | 本当に知りたいこと、解くべきことは何か |
| 2 | [問題を分解する](lessons/02-decomposing-problems.md) | 大きすぎる問題を、確かめられる単位にできるか |
| 3 | [証拠を集める](lessons/03-gathering-evidence.md) | 何を根拠に信じるのか |
| 4 | [仮説を比較する](lessons/04-comparing-hypotheses.md) | 最初に思いついた説明以外に何があるか |
| 5 | [試して間違いを更新する](lessons/05-testing-and-updating.md) | 予想が外れたとき、考えをどう改善するか |
| 6 | [他者へ説明し協力する](lessons/06-explaining-and-collaborating.md) | 一人では解けない問題を、どう一緒に解くか |

この6つは直線ではなく循環します。

```text
問い → 分解 → 証拠 → 仮説 → 実験と更新 → 説明と協力
 ↑                                              ↓
 └──────────── 新しい問いが生まれる ────────────┘
```

## 進め方

1. 各レッスンを読み、最後の「小さな実践」を行う
2. 身近な問題を一つ選び、[統合演習](exercise.md)で6つの力を一巡させる
3. 結論だけでなく、途中で変わった考えを記録する
4. Phase 0へ進んだ後も、難しい課題に出会うたびにこの循環へ戻る

目安は3〜5日です。早く読み終えることより、自分の題材で一度使うことを優先してください。

## 修了条件

- [ ] 事実を尋ねる問いと、判断を求める問いを区別できる
- [ ] 大きな問題を、独立して確かめられる小問題へ分けられる
- [ ] 主張・証拠・推論を区別し、情報源の限界を説明できる
- [ ] 少なくとも2つの仮説を並べ、各仮説を弱める証拠を考えられる
- [ ] 予想、試したこと、結果、更新した考えを記録できる
- [ ] 相手の考えを正確に言い直してから、賛否と理由を伝えられる
- [ ] [統合演習](exercise.md)を第三者に説明し、指摘を受けて1回改善した

点数より、**考えが変わった跡を残せたか**を重視します。最初から正しかったように記録を書き直してはいけません。
