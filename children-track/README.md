# 子ども版 — くるくる探究ラボ

身の回りの「なぜ？」を見つけ、予想し、作り、わざと壊し、だれかに説明し、もっとよくする教材です。

プログラミングを早く覚えることが目的ではありません。道具や流行が変わっても使える、次の循環を自分で回せるようになることが目的です。

```text
観察 → 予想 → 作る → 壊す → 説明 → 改善
 ↑                                      ↓
 └────────── もう一度、観察する ──────────┘
```

## だれのための教材？

主に**8〜14歳くらい**を想定しています。ただし、年齢でコースを分けません。

- 文章を書くのが難しければ、絵、写真、音声、口頭説明で記録する
- 簡単すぎれば、使える材料、時間、重さなどの制約を追加する
- 難しすぎれば、大人と一緒に行うか、一つ前の周へ戻る

一人でも、きょうだい、友だち、家族、学校のグループでも取り組めます。安全確認と対話のため、最初は保護者または指導者が伴走してください。

## 4つの周回

一本道ではありません。同じ6つの動きを、題材と難度を変えて何度も回します。

| 周 | テーマ | 主な材料 | 新しく増える力 | 目安 |
|---|---|---|---|---|
| 1 | [よく見て、くらべる](cycles/01-look-and-compare.md) | 紙、積み木、料理、身近な物 | 観察と公平な比較 | 2〜3回 |
| 2 | [手順とルールを作る](cycles/02-instructions-and-rules.md) | 紙、カード、ゲーム、体 | 曖昧さ、順序、例外 | 3〜4回 |
| 3 | [しくみとデータを調べる](cycles/03-systems-and-data.md) | 記録表、サイコロ、工作 | 測定、複数の仮説、関係 | 4〜6回 |
| 4 | [だれかのために届ける](cycles/04-make-for-someone.md) | 自由。コンピュータは任意 | 利用者、協力、責任、改善 | 6〜10回 |

1回は30〜60分が目安です。一つの周を一日で終える必要はありません。周回の最後に「まだ気になること」が生まれたら成功です。

## 6つの動き

### 1. 観察する

すぐに答えを決めず、見たこと、聞いたこと、測ったことを集めます。「事実」と「自分の考え」を分けます。

### 2. 予想する

結果を見る前に「こうなると思う」と理由を書きます。予想は当てるためではなく、結果から学べるようにするためにあります。

### 3. 作る

完璧な完成品ではなく、考えを試せる小さなものを作ります。紙の模型、料理の手順、遊びのルールでも構いません。

### 4. 壊す

乱暴に壊すことではありません。「どんなときに失敗する？」と意地悪な条件を試します。端、例外、誤解、使いすぎを探します。

### 5. 説明する

何を考え、何が起き、何がまだ分からないかを伝えます。聞く人は、まず自分の言葉で言い直してから質問します。

### 6. 改善する

全部を作り直さず、理由を決めて一つ変えます。変えた後にもう一度観察し、前よりよくなったか確かめます。

## 基本ルール

1. 予想を結果の後で書き換えない
2. 間違いを隠さない。「考えが変わった場所」を宝物にする
3. 人ではなく、アイデアを試す
4. 作品を壊す前に、作った人の許可を取る
5. 刃物、火、熱、電気、薬品、屋外活動、オンライン公開は大人と確認する
6. 写真、名前、位置、学校などの個人情報を許可なく公開しない

## 用意するもの

- 紙、筆記具、テープ
- 積み木、空き箱、カード、輪ゴムなど安全な材料
- [探究シート](templates/inquiry-sheet.md)
- 作品と考えの変化を残す[成長ポートフォリオ](portfolio.md)

コンピュータは必要ありません。第4周で使いたい場合だけ、Scratch、スライド、文章作成、カメラなど、その時点で安全に利用できる道具を選びます。製品の操作方法はこの教材の中心にしません。

## おとなの方へ

[保護者・指導者ガイド](facilitator-guide.md)を最初に読んでください。大人の役割は正解を早く教えることではなく、安全を守り、子どもの観察と考えを言葉にする手助けをすることです。

4周を終えた後は、同じ題材を難しくしてもう一度回しても、興味のある周だけ繰り返しても構いません。高校生相当の読解力が育ったら、[永久層](../foundation-permanent/)、その後に技術本編へ進めます。
