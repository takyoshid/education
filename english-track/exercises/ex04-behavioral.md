# Exercise 04: 行動面接 STAR 回答作成

対応レッスン: Lesson 08「行動面接 (Behavioral Interview) 対策」

---

## この演習について

行動面接の頻出質問5問について、STAR 形式(Situation・Task・Action・Result)で英語の回答を作成します。自分の実際の経験を使って書いてください。経験が浅い場合は、個人プロジェクト・学校のグループ課題・アルバイト経験でも構いません。

所要時間の目安: 90〜120 分(1問あたり15〜25分)

---

## STAR 形式の構成

```
S — Situation (20〜30秒)
    いつ、どこで、どんなプロジェクト・状況だったか

T — Task (10〜20秒)
    あなた個人の役割・責任・目標は何だったか

A — Action (60〜90秒) ★最重要
    あなたが具体的に何をしたか。"I" を主語にして3〜5ステップで

R — Result (20〜30秒)
    数値を含む成果と、あなたが学んだこと

全体の目安: 1〜3分
```

---

## 回答フォーマット

各問題について、以下の形式で書いてください:

```
**Situation:**
(2〜3文)

**Task:**
(1〜2文)

**Action:**
(3〜5文。具体的なステップを「I did X, then I did Y, which led to Z」のような流れで)

**Result:**
(2〜3文。数値か具体的な成果 + 学び)
```

## 自己評価チェックリスト

回答を書いたら以下を確認してください:

- [ ] 主語は常に「I」(We にしていない)
- [ ] Action セクションが最も詳しく、3ステップ以上ある
- [ ] Result に数値か具体的な成果がある
- [ ] 「頑張りました」「改善しました」など曖昧な表現を避けている
- [ ] 全体の長さが1〜3分で読める分量(200〜400単語程度)
- [ ] 声に出して読んで自然に聞こえる

---

## 提出・確認方法

1. 5問すべての回答を書いたら `exercises/solutions/sol04-behavioral.md` を開いて模範解答と比較する
2. 模範解答との違いを分析し、改善点を回答に反映させる
3. 最終的な回答を声に出して1〜3分に収まるか計測する

## 練習方法

**一人での練習:**
書いた台本を見ずに声に出して話す練習をする。最初は台本を見ながらでよいが、最終的に台本なしで話せることを目標にする。

**録音を使った練習:**
スマートフォンで録音して聴き直す。「I」の代わりに「We」を使っていないか、uminの「えーと」相当の "um" や "like" が多すぎないかを確認する。

**Pramp を使った実践:**
https://www.pramp.com でパートナーと模擬面接を行う。無料で使える。
