# Phase 3 実技試験 — コンフリクト解消とPRレビュー対応

知識の再現は[Retrieval Check](retrieval-check.md)で先に確認します。

## 試験条件

- 制限時間: 120分
- 教材・検索・AIは禁止。Gitの組み込みヘルプは使用可
- 第三者が用意したリポジトリのコピーまたは試験用リモートで実施する
- 評価者が競合する2ブランチとレビューコメントを用意する

## 課題

双方に意味のある変更があるマージコンフリクトを調査して解消し、テストを通してPull Requestを作成してください。その後、評価者のレビュー指摘へ根拠付きで対応し、誤操作から復旧できることを示します。

## 受け入れ条件

- 競合前に両ブランチの意図と共通祖先を確認している
- コンフリクトマーカーを消すだけでなく、双方の要件を保っている
- 意味のある単位でコミットし、秘密情報や生成物を含めない
- PRに目的、変更内容、検証方法、残るリスクを書く
- レビュー指摘を採用または却下し、その理由と再検証結果を残す
- 評価者が指定した誤操作を`reflog`、`restore`、`revert`等の適切な方法で復旧する

## 合格条件

必須条件をすべて満たし、第三者レビューを最低1回受けます。PR、レビュー会話、Git履歴、テスト結果、復旧手順を[中央の評価ガイド](../../assessment/)の証拠形式で提出してください。
