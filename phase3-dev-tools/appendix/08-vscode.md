# 付録: VS Code の操作

> **この付録は「早く古くなる側」です。**
>
> ここに書いてあるのは、特定のエディタの画面構成・ショートカット・拡張機能名です。これらは**変わります。**エディタごと乗り換えることもあります。
>
> [レッスン 08](../lessons/08-editor-mastery.md) 本文の概念 — 意味を理解した変更と文字列置換の違い、デバッガの操作モデル、言語サーバとは何か — は、どのエディタでも通用します。**手順が実物と合わなくなっていたら、この付録のほうを直してください。**
>
> 別のエディタを使う場合も、探すべき機能は本文の一覧と同じです。名前と押すキーだけが違います。

対応する本文: [レッスン 08: エディタを使いこなす](../lessons/08-editor-mastery.md)

## 2. まず覚える 10 個

すべてを覚える必要はありません。**この 10 個だけ体に入れれば、手がキーボードから離れる回数が激減します。**

| 操作                  | Mac              | Windows / Linux    |
|-----------------------|------------------|--------------------|
| コマンドパレット       | Cmd + Shift + P  | Ctrl + Shift + P   |
| ファイルを素早く開く   | Cmd + P          | Ctrl + P           |
| 保存                   | Cmd + S          | Ctrl + S           |
| ターミナルを開く       | Ctrl + `         | Ctrl + `           |
| 行をコメントアウト     | Cmd + /          | Ctrl + /           |
| 定義へジャンプ         | F12              | F12                |
| 名前変更(意味を理解)   | F2               | F2                 |
| 次の同じ単語を選択     | Cmd + D          | Ctrl + D           |
| 行を上下に移動         | Option + 上下    | Alt + 上下          |
| デバッグ開始           | F5               | F5                 |

**最も重要なのは 1 行目のコマンドパレット**です。機能名をうろ覚えでも検索できるので、他のショートカットを知らなくてもたどり着けます。迷ったらこれを開いてください。

## 5. デバッガ

### 設定ファイル

初回だけ `launch.json` を作ります。デバッグアイコン → 「launch.json ファイルを作成します」→ 言語を選択。

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "debugpy",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal"
        }
    ]
}
```

### 操作

| 操作               | ショートカット | 説明                                   |
|--------------------|----------------|----------------------------------------|
| Continue           | F5             | 次のブレークポイントまで実行            |
| Step Over          | F10            | 現在の行を実行して次の行へ(関数に入らない) |
| Step Into          | F11            | 現在の行を実行して関数の中に入る        |
| Step Out           | Shift + F11    | 現在の関数を最後まで実行して抜け出る    |
| Stop               | Shift + F5     | デバッグを終了                          |

### パネル

- **Variables**: 現在のスコープの変数と値
- **Watch**: 特定の式を監視して値を確認
- **Call Stack**: 関数の呼び出し履歴
- **Breakpoints**: 設定中のブレークポイント一覧

### デバッグコンソール

停止中に任意の式を評価できます。

```python
len(items)
items[0].price
sum(item.price for item in items)
```

## 6. Git 連携

- ソース管理アイコンで変更ファイルの一覧が出る
- ファイル名をクリックすると diff が出る
- `+` で `git add`、メッセージを書いてチェックマークで `git commit`

編集した行の左端には色のバーが付きます。緑が追加、青が変更、赤の三角が削除です。バーをクリックすると diff と「元に戻す」が出ます。

**ただし、Git の操作を画面から覚えないでください。** [レッスン 01〜06](../lessons/) でコマンドを学ぶのは、何が起きているかを理解するためです。画面のボタンは、理解したあとの近道として使ってください。理解せずにボタンを押していると、壊れたときに直せません。

## 7. 拡張機能

| 用途 | 代表的な拡張機能 |
|---|---|
| 言語サポート(補完・デバッグ) | 各言語の公式拡張 |
| Git の履歴を行単位で見る | GitLens |
| 自動整形 | Prettier |
| 静的解析 | ESLint |
| エラーを行内に表示 | Error Lens |
| HTTP リクエストを送る | REST Client |

**入れすぎないでください。** 拡張機能は起動を遅くし、互いに衝突します。「困ってから入れる」で十分です。困っていないのに入れた拡張は、たいてい使われないまま残ります。
