# Phase 12 実技試験 — 実ユーザーの問題を解き改善する

知識の再現は[Retrieval Check](retrieval-check.md)で先に確認します。

この試験では新しいスターター課題を使わず、既存の[キャップストーン概要](../capstone/overview.md)と[評価ルーブリック](../capstone/evaluation-rubric.md)をTransfer Taskとして使います。

## 試験条件

- 既存3仕様のいずれか、または同等規模の実ユーザー課題を選ぶ
- 実装前に対象ユーザーへ課題を確認し、成功指標を決める
- AIと検索は利用可。採用・却下・検証を`AI-LOG.md`へ記録する
- 完成後、対象ユーザーを含む第三者2名以上からフィードバックを得る

## 必須成果物

- 問題、対象ユーザー、非目標、成功指標を記したDesign Doc
- READMEだけで起動・検証できる成果物と、自動テスト・CIの結果
- 個人情報を除いた利用観察またはユーザーテストの記録
- フィードバック、採用・却下理由、改善前後の差分
- 主要な設計判断、代替案、失敗条件、運用・復旧手順
- 5〜10分のデモと質疑への回答

## 合格条件

- [評価ルーブリック](../capstone/evaluation-rubric.md)で中級以上を満たす
- コアユーザーフローが自動テストされ、第三者が再現できる
- 少なくとも1件のユーザーフィードバックを反映し、再検証している
- 未解決の問題と、次に見直す条件を明記している
- [中央の評価ガイド](../../assessment/)に沿った証拠を提出している
