# 世界で通用するソフトウェアエンジニアへの道

完全初学者が、世界のどこでも通用するソフトウェアエンジニアになるための体系的教材。

## 🌟 旅の始まりに: 180年前、最初のプログラマーは詩人の娘だった

1843年、コンピュータが物理的に存在するより100年も前に、世界初のプログラムを発表した人物がいます。詩人バイロンの娘、**エイダ・ラブレス**です。彼女はチャールズ・バベッジの「解析機関」(歯車式の計算機械の設計)について論文の注釈を書き、その中で機械にベルヌーイ数を計算させる手順 — 史上初の公開されたプログラム — を記述しました。

彼女の言葉は、機械の本質を誰よりも早く見抜いていました。

> 「解析機関は、ジャカード織機が花や葉を織り上げるのとまったく同じように、**代数のパターンを織り上げる**。」

さらに彼女は「この機械はいつか、精緻で科学的な音楽を作曲するかもしれない」とまで予言しています。存在しない機械の可能性を、数学と想像力だけで見通した — 彼女は自分の方法を「**詩的科学(poetical science)**」と呼びました。

これからあなたが始める学習は、この180年続く人類の物語の続きです。ようこそ。

## この教材の設計思想

1. **手を動かして学ぶ** — 全レッスンに演習と模範解答がある。読むだけでは修了できない
2. **なぜ動くかを理解する** — 暗記ではなく原理から。CS基礎を省略しない
3. **世界基準** — 技術用語は英語併記。英語ドキュメントを読み、英語で発信できる力を育てる
4. **プロの現場を再現** — Git、コードレビュー、テスト、設計を初期から習慣化する
5. **AI時代対応** — AIツールを使いこなしつつ、AIに依存しない基礎力を築く

## 各 Phase の構成

```
phaseN-<name>/
├── README.md        # 学習目標・前提・修了条件チェックリスト
├── lessons/         # 01-xx.md 形式のレッスン
├── exercises/       # 演習問題
│   └── solutions/   # 模範解答(解説付き)
└── project/         # Phase 総仕上げのミニプロジェクト
```

## 学習の進め方

1. Phase 0 から順番に進める(Phase 10 の英語学習だけは Phase 2 開始時から並行)
2. 各レッスンの演習を解いてから解答を見る
3. Phase 末の修了条件チェックリストを全て満たしてから次へ進む
4. わからないことは 15 分自力で調べ、それでも解けなければ質問する(質問の仕方も Phase 0 で学ぶ)
