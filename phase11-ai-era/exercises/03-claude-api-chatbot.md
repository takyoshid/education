# 演習 03: Claude API を使ったチャットボット実装

## 目的

Lesson 06 で学んだ Claude API の使い方を実践し、自力で動くチャットボットを実装します。

## 所要時間

90〜120 分

## 前提

- Lesson 06 を完了していること
- Python 3.8 以上の環境があること
- Anthropic の API キーを持っていること

---

## 課題 A: 基本実装 (必須)

以下の仕様を満たすターミナルチャットボットを実装してください。

### 仕様

1. ターミナルで起動してユーザーと会話できる
2. 会話の履歴を保持し、前の会話を参照できる
3. システムプロンプトで「Python プログラミング講師」の役割を設定する
4. `quit` または `exit` で終了できる
5. 各応答の後にトークン使用量を表示する
6. 空の入力をスキップする

### ファイル名

`exercises/03-chatbot/chatbot.py`

### 動作確認

以下のような会話ができることを確認してください。

```
チャットボットを起動しました。終了するには 'quit' と入力してください。
------------------------------------------------------------
あなた: リストと辞書の違いを教えてください

AI: [回答が表示される]

  [tokens: input=XX, output=XX]
------------------------------------------------------------
あなた: それぞれをいつ使えばいいですか？

AI: [前の会話を踏まえた回答が表示される]
```

---

## 課題 B: 機能追加 (推奨)

以下の機能を一つ以上追加してください。

### 選択肢 1: 会話履歴の保存と読み込み

会話終了時に JSON ファイルに保存し、次回起動時に「前の会話を続けますか?」と聞いて続きから会話できるようにする。

```python
# 保存形式の例
# conversation_history.json
[
    {"role": "user", "content": "リストとは何ですか？"},
    {"role": "assistant", "content": "リストは..."}
]
```

### 選択肢 2: コスト集計の表示

会話の最後に、その会話全体で使ったトークン数と推定コスト ($) を表示する。

```
------------------------------------------------------------
会話を終了しました。
総トークン使用量: input=1234, output=567
推定コスト: $0.0021
```

### 選択肢 3: 複数のペルソナ選択

起動時に「どの役割の講師に聞きますか?」と選択肢を表示し、選んだ役割でチャットを開始できるようにする。

```
1: Python 講師
2: セキュリティエンジニア
3: システム設計のアドバイザー

番号を選択してください: _
```

### 選択肢 4: 会話要約機能

`/summarize` コマンドで現在の会話内容を AI に要約させて表示する機能を追加する。

---

## 課題 C: エラーハンドリングの強化 (必須)

Lesson 06 で学んだエラーハンドリングを実装してください。

### 実装すべきエラー処理

1. API キーが設定されていない場合: わかりやすいエラーメッセージと設定方法を表示して終了
2. レート制限エラー: 「X 秒後にリトライします...」と表示して自動リトライ (最大 3 回)
3. ネットワーク接続エラー: 「接続に失敗しました。ネットワークを確認してください」と表示して最後のメッセージを履歴から削除
4. KeyboardInterrupt (Ctrl+C): 「終了します」と表示してクリーンに終了

## ヒント

- `os.environ.get("ANTHROPIC_API_KEY")` で環境変数から読み込む
- `try/except` で `anthropic.RateLimitError`、`anthropic.APIConnectionError`、`anthropic.APIStatusError` を個別に捕捉する
- Lesson 06 の `chatbot.py` サンプルを参考にしてよいが、必ず中身を理解してから使う
- わからない部分は AI に「この部分を説明してください」と聞く (答えをコピーするのではなく)
