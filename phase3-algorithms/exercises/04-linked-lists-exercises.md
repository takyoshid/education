# 演習 04: 連結リスト

## Easy

### E4-1: 連結リストの反転

単方向連結リストの先頭ノード `head` が与えられます。リストを反転して新しい先頭ノードを返してください。

**例:**
```
入力: 1 -> 2 -> 3 -> 4 -> 5 -> None
出力: 5 -> 4 -> 3 -> 2 -> 1 -> None
```

**制約:**
- 空間計算量 O(1) で解くこと(補助リスト不可)

---

### E4-2: 連結リストの中間ノード

単方向連結リストの先頭ノード `head` が与えられます。中間ノードを返してください。ノードが偶数個の場合は後半の先頭を返してください。

**例:**
```
入力: 1 -> 2 -> 3 -> 4 -> 5 -> None  → ノード 3
入力: 1 -> 2 -> 3 -> 4 -> None        → ノード 3
```

**制約:**
- 1 パスで O(1) 空間で解くこと

---

## Medium

### M4-1: 連結リストのサイクル検出 II

単方向連結リストにサイクルがあるとき、サイクルが始まるノードを返してください。サイクルがなければ `None` を返してください。

**制約:**
- O(1) 空間で解くこと(ハッシュセットを使わない)
- フロイドの亀とウサギアルゴリズムを発展させた方法で解けます

---

### M4-2: 2 つの連結リストを合計する (Add Two Numbers)

各桁を表すノードからなる逆順の連結リスト 2 つが与えられます。2 数の和を同じ形式で返してください。

**例:**
```
l1: 2 -> 4 -> 3  (342 を表す)
l2: 5 -> 6 -> 4  (465 を表す)
出力: 7 -> 0 -> 8 (807 を表す)
```

---

## Hard

### H4-1: K グループごとに反転 (Reverse Nodes in k-Group)

連結リストを k ノードごとのグループに分け、各グループを反転してください。末尾のグループが k 未満のノード数の場合はそのままにしてください。

**例:**
```
head = 1 -> 2 -> 3 -> 4 -> 5, k = 2
出力:  2 -> 1 -> 4 -> 3 -> 5

head = 1 -> 2 -> 3 -> 4 -> 5, k = 3
出力:  3 -> 2 -> 1 -> 4 -> 5
```
