# 演習 07: ソートアルゴリズム

## Easy

### E7-1: マージソートの実装

マージソートを一から実装してください。

**入力:** 整数配列 `arr`
**出力:** ソートされた新しい配列

**例:**
```
[38, 27, 43, 3, 9, 82, 10]  → [3, 9, 10, 27, 38, 43, 82]
```

---

### E7-2: 配列の K 番目に大きい要素

整数配列 `nums` と整数 `k` が与えられます。k 番目に大きい要素を返してください。

**例:**
```
nums = [3, 2, 1, 5, 6, 4], k = 2  → 5
nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4  → 4
```

Python の `sorted()` を使って O(n log n) で解いてください。次に `heapq` を使って O(n log k) で解いてください。

---

## Medium

### M7-1: クイックソートの実装

クイックソートを一から実装してください。ランダムピボットを使って最悪ケース O(n^2) を回避してください。

**入力:** 整数配列 `arr`
**出力:** インプレース(元の配列を変更)でソート

---

### M7-2: 色の並べ替え (Sort Colors / Dutch National Flag)

`0`(赤)、`1`(白)、`2`(青)のみを含む整数配列 `nums` を、0, 1, 2 の順にインプレースでソートしてください。

**例:**
```
nums = [2, 0, 2, 1, 1, 0]  → [0, 0, 1, 1, 2, 2]
```

**制約:**
- 標準ライブラリのソート関数を使わないこと
- O(n) 時間、O(1) 空間で解くこと
- ヒント: Three-way partitioning (Dutch National Flag アルゴリズム)

---

## Hard

### H7-1: 最小の k 個の数 (Smallest K Numbers)

整数配列 `arr` と整数 `k` が与えられます。最小の k 個の数を返してください(順不同でよい)。

**例:**
```
arr = [4, 5, 1, 6, 2, 7, 3, 8], k = 4  → [1, 2, 3, 4]
```

**3通りのアプローチで解いてください:**
1. ソートして先頭 k 個を返す: O(n log n)
2. ヒープを使う: O(n log k)
3. Quickselect を使う: O(n) 平均
