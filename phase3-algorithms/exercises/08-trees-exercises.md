# 演習 08: 木構造と二分探索木、ヒープ

## Easy

### E8-1: 二分木の最大深さ

二分木のルートノード `root` が与えられます。木の最大深さ(ルートから最も遠い葉までのノード数)を返してください。

**例:**
```
      3
     / \
    9  20
       / \
      15   7

最大深さ: 3
```

---

### E8-2: 二分木のレベル順走査

二分木のルートノード `root` が与えられます。レベル順(BFS)で各ノードの値をリストのリストで返してください。

**例:**
```
    3
   / \
  9  20
     / \
    15   7

→ [[3], [9, 20], [15, 7]]
```

---

## Medium

### M8-1: BST の検証 (Validate Binary Search Tree)

二分木のルートノード `root` が与えられます。これが有効な BST かどうかを判定してください。

**BST の条件**: すべてのノードについて、左部分木のすべての値 < そのノード < 右部分木のすべての値

**例:**
```
    2           5
   / \         / \
  1   3        1   4
               / \
              3   6
True        False (4 の左の子 3 は 5 より小さいが...)
```

---

### M8-2: K 番目に小さい BST の要素

BST のルートノード `root` と整数 `k` が与えられます。BST の k 番目に小さい値を返してください。

**例:**
```
BST: [3, 1, 4, null, 2], k = 1  → 1
BST: [5, 3, 6, 2, 4, null, null, 1], k = 3  → 3
```

**ヒント:** 中順走査は BST の昇順走査になります。

---

## Hard

### H8-1: 二分木の直径 (Diameter of Binary Tree)

二分木のルートノード `root` が与えられます。木の直径(任意の 2 ノード間の最長経路の辺の数)を返してください。

**例:**
```
      1
     / \
    2   3
   / \
  4   5

直径: 3 (4-2-1-3 または 5-2-1-3)
```
