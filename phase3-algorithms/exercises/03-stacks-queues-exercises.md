# 演習 03: スタックとキュー

## Easy

### E3-1: 有効な括弧 (Valid Parentheses)

文字列 `s` が `(`, `)`, `{`, `}`, `[`, `]` のみからなるとき、括弧の対応が正しいかどうかを判定してください。

**例:**
```
"()"       → True
"()[]{}"   → True
"(]"       → False
"([)]"     → False
"{[]}"     → True
```

---

### E3-2: スタックで最小値を O(1) で取得

通常のスタック操作(push/pop/peek)に加えて、**現在スタックに入っている最小値を O(1) で返す** `get_min()` 操作をサポートするスタッククラスを実装してください。

**例:**
```python
s = MinStack()
s.push(5)
s.push(3)
s.push(7)
s.push(2)
s.get_min()  # 2
s.pop()      # 2 を取り出す
s.get_min()  # 3
```

**ヒント:** 補助スタックを使います。

---

## Medium

### M3-1: 逆ポーランド記法の評価 (Evaluate Reverse Polish Notation)

逆ポーランド記法(後置記法)で書かれた数式を評価して結果を返してください。

**例:**
```
tokens = ["2","1","+","3","*"]  → 9  (2+1)*3
tokens = ["4","13","5","/","+"] → 6  4+(13/5)
tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"] → 22
```

使える演算子: `+`, `-`, `*`, `/` (除算は整数除算、ゼロ方向に丸める)

---

### M3-2: デイリー・テンペラチャー (Daily Temperatures)

整数配列 `temperatures` が与えられます。各日について、「次にその日より暖かくなるまでの日数」を配列で返してください。より暖かい日が来ない場合は 0 とします。

**例:**
```
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
→ [1, 1, 4, 2, 1, 1, 0, 0]
```

**ヒント:** 単調スタック(Monotonic Stack)というパターンを使います。

---

## Hard

### H3-1: LRU キャッシュ (LRU Cache)

最近最も使われていないキャッシュ方式(Least Recently Used Cache)を実装してください。

キャッシュ容量 `capacity` を引数に取り、以下の操作を O(1) で行ってください:

- `get(key)`: key が存在すれば値を返す。なければ -1
- `put(key, value)`: key-value ペアを挿入。容量超過の場合、最も長く使われていないエントリを削除

**例:**
```python
cache = LRUCache(2)
cache.put(1, 1)
cache.put(2, 2)
cache.get(1)    # 1
cache.put(3, 3) # キャッシュ容量超過 → key=2 を削除
cache.get(2)    # -1 (削除済み)
```

**ヒント:** 辞書 + 双方向連結リストで実装します。Python では `collections.OrderedDict` でも実装できます。
