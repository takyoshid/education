# Phase 3 実技試験 — 依存関係スケジューラー

## 試験条件

- 制限時間: 120分
- AI・検索・既存解答禁止。Python標準ライブラリのリファレンスは可
- `starter/` をコピーし、既存APIを変更せず実装する

## 課題

タスクと依存関係から、実行可能な順序を返すスケジューラーを完成させます。入力順に依存しない決定的な結果、未知タスク、自己依存、循環を扱ってください。

### 受け入れ条件

- 依存先は必ず先に現れる
- 複数の候補がある場合は辞書順で選ぶ
- 循環がある場合、循環に関係するタスクを含む説明付き例外を返す
- 未知タスクと自己依存を拒否する
- 入力を変更しない
- 時間計算量と空間計算量を説明する
- 10万タスクの鎖を再帰なしで処理できる

```bash
cd starter
python3 -m unittest discover -s tests -v
```

## 追加設問

1. DFS方式とKahn方式を比較してください。
2. 出力を辞書順にすることで計算量はどう変わりますか。
3. すべての有効な順序を列挙すると、なぜ急激に難しくなりますか。
4. タスクが実行中に追加される場合、現在の設計をどう変えますか。

80点以上、循環検出と大規模入力を必須として合格です。
