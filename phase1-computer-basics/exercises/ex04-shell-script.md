## 問題 1: 基本スクリプト

次の要件を満たすスクリプト `greet.sh` を作成してください。

**要件:**
- スクリプトに名前を引数として渡すと、「おはようございます、<名前>！」と表示する
- 引数がない場合は「使い方: greet.sh <名前>」と表示して終了する（終了コード 1）
- スクリプトは実行権限を付与して `./greet.sh Alice` で実行できること

**実行例:**
```bash
$ ./greet.sh Alice
おはようございます、Alice！

$ ./greet.sh
使い方: greet.sh <名前>
```

## 問題 2: 条件分岐の練習

次の要件を満たすスクリプト `classify.sh` を作成してください。

**要件:**
- 引数に数値を受け取る
- 0 未満の場合: 「負の数」と表示
- 0 の場合: 「ゼロ」と表示
- 1 以上 100 以下の場合: 「1〜100 の正の数」と表示
- 101 以上の場合: 「100 より大きい数」と表示
- 引数がない場合はエラーメッセージを表示

**実行例:**
```bash
$ ./classify.sh -5
負の数
$ ./classify.sh 0
ゼロ
$ ./classify.sh 42
1〜100 の正の数
$ ./classify.sh 200
100 より大きい数
```

## 問題 3: ループの練習

次の要件を満たすスクリプト `fizzbuzz.sh` を作成してください。

**要件:**
- 1 から 30 までの数字を順に処理する
- 3 の倍数のとき: 「Fizz」を表示
- 5 の倍数のとき: 「Buzz」を表示
- 3 と 5 両方の倍数のとき: 「FizzBuzz」を表示

**実行例（一部）:**
```bash
$ ./fizzbuzz.sh
1
2
Fizz
4
Buzz
Fizz
7
...
FizzBuzz
...
```

## 問題 4: ファイル処理スクリプト

次の要件を満たすスクリプト `file_info.sh` を作成してください。

**要件:**
- 引数にディレクトリパスを受け取る
- そのディレクトリに存在するファイルをすべて処理する
- 各ファイルについて次の情報を表示する:
  - ファイル名
  - 行数（`wc -l`）
  - ファイルサイズ（`ls -lh` から取得、または `du -sh`）
- 処理が終わったら「合計: X ファイル処理しました」と表示する
- ディレクトリが存在しない場合はエラーメッセージを表示する

**実行例:**
```bash
$ ./file_info.sh ~/practice/phase1-ex03
access.log: 15 行
scores.txt: 8 行
words.txt: 13 行
合計: 3 ファイル処理しました
```

## 問題 5: 関数を使ったスクリプト

次の要件を満たすスクリプト `calculator.sh` を作成してください。

**要件:**
- 4つの関数 `add`、`subtract`、`multiply`、`divide` を定義する
- それぞれ2つの引数（数値）を受け取り、計算結果を出力する
- `divide` は第2引数が 0 のときエラーメッセージを表示して終了コード 1 を返す
- メインの処理で各関数を呼び出して結果を表示する

**実行例:**
```bash
$ ./calculator.sh
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3
10 / 0 = エラー: ゼロ除算はできません
```

## 問題 6: 応用問題 - ログ解析スクリプト

`access.log`（演習 03 で作成したもの）を解析するスクリプト `analyze_log.sh` を作成してください。

**要件:**
- 引数にログファイルのパスを受け取る
- 次の情報を表示する:
  1. ファイル内の総リクエスト数
  2. ステータスコード 200 の件数と全体に対するパーセンテージ
  3. ステータスコード 404 の件数
  4. ステータスコード 500 の件数
  5. 最もアクセスが多い URL パス（Top 1）
- ファイルが存在しない場合はエラーで終了

**実行例:**
```bash
$ ./analyze_log.sh access.log
=== ログ解析レポート ===
ファイル: access.log
総リクエスト数: 15
200 レスポンス: 10 件 (66%)
404 エラー: 3 件
500 エラー: 2 件
最多アクセス URL: /api/users (3 件)
```

**ヒント:**
- `grep | wc -l` でステータスコード別の件数を取得できる
- パーセンテージは `$((count * 100 / total))` で計算できる（整数演算）
- URL のTop 1 は `grep | awk | sort | uniq -c | sort -rn | head -1` で取得できる
