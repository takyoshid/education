# 演習 01: 2進数・16進数の変換

## 目的

Lesson 01 で学んだ2進数・16進数の変換を手を動かして定着させます。
計算は紙または暗算で行い、最後にターミナルで確認しましょう。

---

## 問題 5: 2進数 ↔ 16進数

2. `01110001`

---

## 問題 6: ターミナルで確認

計算が終わったら、ターミナルで答えを確認しましょう。

```bash
# macOS / Linux で Python を使って変換を確認できます
$ python3 -c "print(int('1010', 2))"     # 2進数 → 10進数
$ python3 -c "print(bin(42))"             # 10進数 → 2進数
$ python3 -c "print(int('0xFF', 16))"    # 16進数 → 10進数
$ python3 -c "print(hex(200))"           # 10進数 → 16進数
```

または `bc` コマンド（macOS/Linux）を使う方法:

```bash
# 2進数を10進数に変換（ibase=入力基数、obase=出力基数）
$ echo "ibase=2; 10111011" | bc

# 10進数を2進数に変換
$ echo "obase=2; 42" | bc

# 10進数を16進数に変換
$ echo "obase=16; 200" | bc
```
