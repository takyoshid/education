# 解答 01: 2進数・16進数の変換

---

## 解答の前に: 考え方の整理

### 2進数 → 10進数 の手順

各桁に「重み」をかけて合計する。右端が 2^0 = 1、左に行くほど2倍。

```
桁位置（右から）:  7    6    5    4    3    2    1    0
重み:            128   64   32   16    8    4    2    1
```

### 10進数 → 2進数 の手順

2で繰り返し割り、余りを下から並べる。

### 16進数 ↔ 2進数 の変換のコツ

**4ビット = 1桁の16進数**という対応を覚える。
```
0000=0, 0001=1, 0010=2, 0011=3
0100=4, 0101=5, 0110=6, 0111=7
1000=8, 1001=9, 1010=A, 1011=B
1100=C, 1101=D, 1110=E, 1111=F
```

---

## 問題 1: 2進数 → 10進数 の解答

**1. `0101`**
```
0×8 + 1×4 + 0×2 + 1×1 = 4 + 1 = 5
```

**2. `1010`**
```
1×8 + 0×4 + 1×2 + 0×1 = 8 + 2 = 10
```

**3. `11001`**
```
1×16 + 1×8 + 0×4 + 0×2 + 1×1 = 16 + 8 + 1 = 25
```

**4. `10111011`**
```
1×128 + 0×64 + 1×32 + 1×16 + 1×8 + 0×4 + 1×2 + 1×1
= 128 + 0 + 32 + 16 + 8 + 0 + 2 + 1
= 187
```

**5. `11111111`**
```
128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255
```
これは 2^8 - 1 = 255 で、1バイトの最大値。

**ターミナルで確認:**
```bash
$ python3 -c "print(int('11111111', 2))"
255
```

## 問題 2: 10進数 → 2進数 の解答

**1. 7**
```
7 ÷ 2 = 3 余り 1
3 ÷ 2 = 1 余り 1
1 ÷ 2 = 0 余り 1
下から読む: 111 → 8桁: 00000111
```

**2. 42**
```
42 ÷ 2 = 21 余り 0
21 ÷ 2 = 10 余り 1
10 ÷ 2 =  5 余り 0
 5 ÷ 2 =  2 余り 1
 2 ÷ 2 =  1 余り 0
 1 ÷ 2 =  0 余り 1
下から読む: 101010 → 8桁: 00101010
確認: 32 + 8 + 2 = 42 正しい
```

**3. 100**
```
100 ÷ 2 = 50 余り 0
 50 ÷ 2 = 25 余り 0
 25 ÷ 2 = 12 余り 1
 12 ÷ 2 =  6 余り 0
  6 ÷ 2 =  3 余り 0
  3 ÷ 2 =  1 余り 1
  1 ÷ 2 =  0 余り 1
下から読む: 1100100 → 8桁: 01100100
確認: 64 + 32 + 4 = 100 正しい
```

**4. 200**
```
200 ÷ 2 = 100 余り 0
100 ÷ 2 =  50 余り 0
 50 ÷ 2 =  25 余り 0
 25 ÷ 2 =  12 余り 1
 12 ÷ 2 =   6 余り 0
  6 ÷ 2 =   3 余り 0
  3 ÷ 2 =   1 余り 1
  1 ÷ 2 =   0 余り 1
下から読む: 11001000
確認: 128 + 64 + 8 = 200 正しい
```

**5. 255**
```
255 = 11111111（すべてのビットが1）
確認: 128+64+32+16+8+4+2+1 = 255 正しい
```

## 問題 3: 16進数 → 10進数 の解答

**1. `0x0F`**
```
0×16 + 15×1 = 15
```

**2. `0x1A`**
```
1×16 + 10×1 = 16 + 10 = 26
```

**3. `0x7F`**
```
7×16 + 15×1 = 112 + 15 = 127
```

**4. `0xAB`**
```
10×16 + 11×1 = 160 + 11 = 171
```

**5. `0xFF`**
```
15×16 + 15×1 = 240 + 15 = 255
（16進数 FF = 2進数 11111111 = 1バイトの最大値）
```

## 問題 4: 10進数 → 16進数 の解答

**1. 10**
```
10 ÷ 16 = 0 余り 10 → A
答え: 0xA
```

**2. 31**
```
31 ÷ 16 = 1 余り 15 → F
答え: 0x1F
確認: 1×16 + 15 = 31 正しい
```

**3. 128**
```
128 ÷ 16 = 8 余り 0
答え: 0x80
確認: 8×16 + 0 = 128 正しい
```

**4. 200**
```
200 ÷ 16 = 12 余り 8
12 → C
答え: 0xC8
確認: 12×16 + 8 = 192 + 8 = 200 正しい
```

**5. 255**
```
255 ÷ 16 = 15 余り 15
15 → F, 15 → F
答え: 0xFF
```

## 問題 5: 2進数 ↔ 16進数 の解答

4ビットずつ区切って変換するのがポイント。

**1. `11001010`**
```
1100 1010
  C    A
答え: 0xCA
確認: 12×16 + 10 = 192 + 10 = 202 = 128+64+8+2 正しい
```

**2. `01110001`**
```
0111 0001
  7    1
答え: 0x71
確認: 7×16 + 1 = 112 + 1 = 113 = 64+32+16+1 正しい
```

**3. `10101010`**
```
1010 1010
  A    A
答え: 0xAA
確認: 10×16 + 10 = 160 + 10 = 170 = 128+32+8+2 正しい
```

## 問題 7: 応用問題の解答

**1. `#FF5733` の RGB 分解:**
```
FF → R: 15×16 + 15 = 255
57 → G: 5×16 + 7 = 87
33 → B: 3×16 + 3 = 51

RGB(255, 87, 51) = 赤に近いオレンジ色
```

**2. `192.168.1.1` の各オクテットを2進数で:**
```
192 = 11000000
168 = 10101000
  1 = 00000001
  1 = 00000001

つまり: 11000000.10101000.00000001.00000001
```

**3. 1バイトと2バイトの最大値:**
```
1バイト（8ビット）: 2^8 - 1 = 256 - 1 = 255
2バイト（16ビット）: 2^16 - 1 = 65536 - 1 = 65535
```

## よくある間違いとポイント

1. **2進数の桁の重みを間違える**: 右端から 2^0, 2^1, 2^2... の順であることを確認する
2. **10進数→2進数で余りを逆に読む**: 最後の余りが最上位ビット（左端）になる
3. **16進数の A〜F を忘れる**: 10=A, 11=B, 12=C, 13=D, 14=E, 15=F を確実に覚える

**一発で覚えるコツ:**
- `0xFF = 255 = 1バイトの最大値`
- `0x10 = 16 = 16^1`
- `0x100 = 256 = 16^2`
