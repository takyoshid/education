# Phase 1 実技試験 — 壊れたシェル処理の診断と安全な修正

知識の再現は[Retrieval Check](retrieval-check.md)で先に確認します。

## 試験条件

- 制限時間: 90分
- 教材・検索・AIは禁止。`man`、`--help`、シェルの組み込みヘルプは使用可
- 第三者が用意した作業用ディレクトリのコピーで実施する
- 最初の20分はファイルを変更せず、観察と仮説だけを記録する

## 課題

空白を含むファイル名、存在しない入力、重複行を含むログを処理する壊れたシェルスクリプトを診断し、元データを失わないよう修正してください。具体的な入力と故障箇所は試験開始時に第三者が指定します。

## 受け入れ条件

- 終了コードと標準出力・標準エラーを用途別に扱う
- パスを引用し、空白やglobを含む名前を安全に処理する
- 入力不在やコマンド失敗時に、途中の出力を完成品として残さない
- `sort`、`uniq`、`grep`などを組み合わせ、指定された集計結果を再現する
- 元データを変更せず、修正前後の出力を比較する
- `shellcheck`が利用可能なら結果を保存し、未導入ならその旨を記録する

## 提出物と合格条件

`commands.txt`、`diagnosis.md`、修正したスクリプト、正常・異常系の実行結果、5分以内の説明を提出します。全受け入れ条件を満たし、第三者がREADMEだけで再現できれば合格です。証拠は[中央の評価ガイド](../../assessment/)に従って保存してください。
