# Phase 1: コンピュータの仕組みと CLI / Linux 基礎

## 概要

このフェーズでは、ソフトウェアエンジニアとして働く上で欠かせない「土台」を学びます。
コンピュータが何者なのか、OS がどう動くのか、そしてターミナルを自在に操る技術を身につけます。
これらは、どんなプログラミング言語を学ぶにしても、どんなフレームワークを使うにしても、
土台として常に使い続ける知識です。

## 🌟 旅の始まりに: 海軍准将が配り歩いた「1ナノ秒」

コンピュータ黎明期の伝説的プログラマー、グレース・ホッパー海軍准将は、講演のたびに聴衆へ奇妙なものを配りました。**約30cmの電線**です。

「これが1ナノ秒です」— 光(電気信号)が**1ナノ秒(10億分の1秒)に進める距離**が、ちょうどこの長さなのです。彼女は続けます。「衛星通信がなぜ遅れるのか、コンピュータがなぜこれ以上速くできないのか、将軍たちに説明するとき、この線を見せるんです」。ちなみにマイクロ秒は約300mの電線の束で、「マイクロ秒を無駄にしたら、この束を思い出しなさい」と笑わせました。

目に見えない世界を、手で触れられる長さに変える — これが Phase 1 でやることです。CPU、メモリ、プロセス、ネットワーク。画面の裏側の見えない仕組みに「物理的な実感」を持っている人のコードは、確実に一段深くなります。30cm の電線を、頭の片隅に置いて進んでください。

## 修了条件チェックリスト

以下をすべて達成したら Phase 1 修了です。

### 知識

- [ ] CPU、メモリ、ストレージの役割を自分の言葉で説明できる
- [ ] 2進数と16進数の相互変換ができる（8ビット程度）
- [ ] プロセス、ファイルシステム、パーミッションとは何かを説明できる
- [ ] シェルとターミナルの違いを説明できる
- [ ] PATH とは何かを説明できる
- [ ] IP アドレス、DNS、URL、HTTP の役割を概要レベルで説明できる

### 技能

- [ ] `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `less` を使いこなせる
- [ ] パイプ (`|`) とリダイレクト (`>`, `>>`, `<`) を使えるコマンドを書ける
- [ ] 環境変数を設定・確認できる
- [ ] `grep`, `find`, `sort`, `uniq`, `head`, `tail` でテキスト処理ができる
- [ ] 変数・条件分岐・ループを含む 20 行程度のシェルスクリプトを書ける
- [ ] Homebrew（macOS）または apt（Linux）でパッケージをインストールできる

### プロジェクト

- [ ] 総仕上げプロジェクト「学習ログ管理ツール」を完成させ、動作確認できる

## 学習の進め方

1. 各レッスンを読みながら、必ずターミナルでコマンドを実際に打つこと
2. 「確認問題」は必ず自分で答えを考えてから答えを見ること
3. 演習は答えを見る前に 20 分以上自力で取り組むこと
4. 詰まったときは `man コマンド名` でマニュアルを読む習慣をつけること

## 注意事項

- `rm` コマンドでの削除は取り消せません。コマンドの意味を理解してから実行してください
- `sudo` を使うコマンドはシステムに影響します。必ず内容を理解してから実行してください
- 自分のホームディレクトリ (`~/`) 以外のディレクトリは慎重に操作してください
