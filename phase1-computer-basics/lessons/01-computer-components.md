## 学習目標

- コンピュータを構成する主要なハードウェアの役割を説明できる

- ビット（bit）とバイト（byte）の関係を説明できる

## 1. コンピュータの主要構成要素

コンピュータは大きく分けて次の要素で構成されています。

```
+--------------------------------------------------+
|  コンピュータ                                      |
|                                                  |
|  +----------+    +----------+    +----------+    |
|  |   CPU    |    |  Memory  |    | Storage  |    |
|  | 処理装置  |<-->| (RAM)    |<-->|  (SSD/   |    |
|  |          |    | 一時記憶  |    |   HDD)   |    |
|  +----------+    +----------+    | 永続記憶  |    |
|       ^                          +----------+    |
|       |                                          |
|  +----------+                                    |
|  |  入出力   |  (キーボード、マウス、ディスプレイ...)  |
|  +----------+                                    |
+--------------------------------------------------+
```

### 1.1 CPU（Central Processing Unit / 中央処理装置）

CPU はコンピュータの「頭脳」です。計算と命令の実行を担当します。

**役割:**
- プログラムの命令を読み取り、実行する
- 数値の計算、論理演算（AND/OR など）を行う
- メモリから命令とデータを読み書きする

**主な仕様:**
- **クロック周波数（clock frequency）**: 1秒間に何回処理できるかを表す。単位は GHz（ギガヘルツ）。例: 3.2 GHz = 1秒間に 32億回の処理
- **コア数（core count）**: 処理ユニットの数。コアが多いほど並列処理が得意。例: 8コア CPU は同時に 8つの処理を並行できる
- **キャッシュ（cache）**: CPU 内部の超高速な一時記憶領域

**プログラマーから見た CPU:**
コードを書くとき、CPU の速度を意識することは少ないですが、「計算量」（アルゴリズムの複雑さ）は CPU に直結します。無駄な計算を減らすことがプログラム高速化の基本です。

### 1.2 メモリ（Memory / RAM）

RAM（Random Access Memory）は「作業机」に例えられます。現在実行中のプログラムとデータを一時的に保存します。

**役割:**
- 実行中のプログラムのコードを保持する
- プログラムが使う変数やデータを保持する
- CPU との高速なデータのやり取りを行う

**重要な特性:**
- **揮発性（volatile）**: 電源を切るとデータが消える
- **高速アクセス**: ストレージの 100〜1000 倍速い
- **容量の目安**: 現代の開発用 PC は 16GB〜32GB が一般的

**プログラマーから見たメモリ:**
プログラムを書くとき、変数に値を代入すると、その値はメモリに書き込まれます。メモリが足りなくなると「メモリ不足」エラーが発生します。

### 1.3 ストレージ（Storage）

SSD（Solid State Drive）や HDD（Hard Disk Drive）は「本棚」に例えられます。電源を切ってもデータが残ります。

**役割:**
- OS（オペレーティングシステム）を保存する
- プログラム（アプリケーション）を保存する
- ユーザーのファイルを保存する

**重要な特性:**
- **不揮発性（non-volatile）**: 電源を切ってもデータが残る
- **大容量**: 現代の PC は 256GB〜2TB が一般的
- **メモリより低速**: アクセス速度はメモリの 10〜100 分の 1

**SSD vs HDD:**
| | SSD | HDD |
|---|---|---|
| 速度 | 速い | 遅い |
| 容量あたりの価格 | 高い | 安い |
| 衝撃への強さ | 強い | 弱い |
| 現在の主流 | はい | 徐々に減少中 |

### 1.4 これらがどう連携するか

プログラムを実行するときの流れ:

```
1. ストレージからプログラムのコードをメモリに読み込む
2. CPU がメモリからコードを読み取り、実行する
3. 実行結果（変数の値など）をメモリに書き込む
4. 必要に応じてストレージに保存する（ファイル書き込み）
```

たとえば、VS Code（テキストエディタ）を起動するとき:

```
SSD（VS Code のプログラムファイル）
  → メモリ（VS Code がメモリに展開される）
    → CPU（VS Code の命令を実行）
      → ディスプレイ（画面に表示）
```

## 2. 数値の表現: 2進数と16進数

### 2.1 なぜコンピュータは2進数を使うのか

コンピュータの内部は電気回路でできています。電気には「流れている（ON）」と「流れていない（OFF）」の2種類の状態しかありません。この2状態を数値で表すのが**2進数（binary / バイナリ）**です。

- `0` = OFF（電気が流れていない）
- `1` = ON（電気が流れている）

### 2.2 ビットとバイト

| 単位 | 意味 | 例 |
|------|------|-----|
| **ビット（bit）** | 0 か 1 の1桁。最小単位 | `1` |
| **バイト（byte）** | 8ビットのまとまり | `01000001` |

バイトとその上位単位:

| 単位 | 大きさ | 目安 |
|------|--------|------|
| 1 byte | 8 bit | 英字1文字 |
| 1 KB（キロバイト） | 1,024 bytes | テキストファイル1ページ程度 |
| 1 MB（メガバイト） | 1,024 KB | 写真1枚程度 |
| 1 GB（ギガバイト） | 1,024 MB | 映画1本程度 |
| 1 TB（テラバイト） | 1,024 GB | 大量のデータ |

### 2.3 2進数を理解する

10進数（私たちが普段使う数）は0〜9の10種類の数字を使い、桁が上がると10倍になります。

2進数は0〜1の2種類の数字を使い、桁が上がると2倍になります。

```
10進数の桁の意味:
  1000  100  10   1
   10^3 10^2 10^1 10^0

2進数の桁の意味:
   8    4    2    1
  2^3  2^2  2^1  2^0
```

**2進数 → 10進数 変換の例:**

```
2進数: 1 0 1 1
       8 4 2 1  <- 各桁の重み

計算: 1×8 + 0×4 + 1×2 + 1×1
    = 8 + 0 + 2 + 1
    = 11（10進数）
```

**10進数 → 2進数 変換の例（13を変換）:**

```
13 ÷ 2 = 6 余り 1  <- 最初の余りが最下位ビット
 6 ÷ 2 = 3 余り 0
 3 ÷ 2 = 1 余り 1
 1 ÷ 2 = 0 余り 1  <- 最後の余りが最上位ビット

下から読む: 1 1 0 1
答え: 2進数 1101
確認: 8+4+0+1 = 13 正しい
```

**練習: よく使う2進数の値を覚えよう**

| 10進数 | 2進数（8桁） |
|--------|------------|
| 0      | 0000 0000  |
| 1      | 0000 0001  |
| 2      | 0000 0010  |
| 4      | 0000 0100  |
| 8      | 0000 1000  |
| 127    | 0111 1111  |
| 128    | 1000 0000  |
| 255    | 1111 1111  |

8ビット（1バイト）で表せる最大値は 255（= 2^8 - 1）です。

### 2.4 16進数（hexadecimal）

2進数は人間が読みにくいため、16進数がよく使われます。16進数は0〜9とA〜Fの16種類を使います。

| 10進数 | 16進数 | 2進数 |
|--------|--------|-------|
| 0  | 0 | 0000 |
| 1  | 1 | 0001 |
| 2  | 2 | 0010 |
| 3  | 3 | 0011 |
| 4  | 4 | 0100 |
| 5  | 5 | 0101 |
| 6  | 6 | 0110 |
| 7  | 7 | 0111 |
| 8  | 8 | 1000 |
| 9  | 9 | 1001 |
| 10 | A | 1010 |
| 11 | B | 1011 |
| 12 | C | 1100 |
| 13 | D | 1101 |
| 14 | E | 1110 |
| 15 | F | 1111 |

**なぜ16進数が便利か:**

4ビット = 1桁の16進数 という対応がとてもきれいです。

```
2進数:  1010  1111
16進数:   A     F   -> AF

2進数の8桁（1バイト）= 16進数の2桁
```

16進数は先頭に `0x` をつけて表記することが多いです。例: `0xFF` = 255

**16進数 → 10進数 変換の例:**

```
0x2A
  2×16 + 10×1
= 32 + 10
= 42
```

**コードで見かける16進数の例:**
- 色の指定: `#FF5733`（RGB 各 1 バイト）
- メモリアドレス: `0x7fff5fbff8f0`
- ファイルのバイナリデータ

## 3. 文字のエンコーディング（補足）

コンピュータは数値しか扱えないので、文字も数値として表します。
- `A` = 65 (10進数) = 0x41 = 01000001 (2進数)
- `a` = 97 (10進数) = 0x61 = 01100001 (2進数)

この対応表を**文字コード（character encoding）**といいます。
代表的なものに **ASCII**（英数字・記号）と **UTF-8**（世界中の文字）があります。
UTF-8 は現代の Web 標準で、日本語も扱えます。

## 🌟 コラム: 手で織られたソフトウェア

アポロ宇宙船の誘導コンピュータのプログラムは、驚くべき形で「書き込まれて」いました。**コアロープメモリ** — 小さな磁気リングに電線を通すか(1)、迂回させるか(0)で、ビットを一つひとつ物理的に表現する記憶装置です。

そしてこの「織り込み」作業を担ったのは、繊維工場出身の熟練女性工員たちでした。プログラムの完成には数ヶ月がかかり、たった1ビットの誤りも許されません。月に行くソフトウェアは、文字通り**人の手で一本ずつ編まれた織物**だったのです。エンジニアたちはこのメモリを、敬意を込めて「LOL メモリ(Little Old Ladies memory)」と呼びました。

メモリの中の 0 と 1 は、抽象的な記号に思えるかもしれません。しかしそれは常に物理的な実在 — かつては手で編まれた電線、今は数ナノメートルの回路に蓄えられた電荷 — です。この「ビットには実体がある」という感覚は、コンピュータを学ぶ間ずっと、あなたの理解に重みを与えてくれます。

## 💡 コラム: CPU の 1 秒は、SSD の数日 — キッチンで考える

コンピュータをレストランの厨房に例えると: **CPU は料理人**、**メモリ(RAM)は調理台**、**ストレージは冷蔵庫と倉庫**です。調理台(メモリ)が広いほど多くの料理を並行して進められ、狭いといちいち倉庫(ストレージ)と往復して遅くなります。「メモリ増設で PC が速くなる」のは調理台を広くしているのです。

速度差を人間の時間に換算した有名な例えがあります。CPU の 1 クロックを「1 秒」とすると:

- メモリへのアクセス: 数分(調理台の端まで手を伸ばす)
- SSD へのアクセス: 数日(近所の倉庫まで買い出し)
- HDD へのアクセス: 数ヶ月(海外から船便で取り寄せ)

プログラムの速さを考えるとき、この「距離感」は一生使う直感になります。「ディスクに触る処理は桁違いに遅い」— これを体で覚えている人が、速いプログラムを書きます。

## まとめ

- CPU は処理、メモリ（RAM）は一時記憶、ストレージは永続記憶という役割分担がある
- プログラムはストレージ → メモリ → CPU の順に処理される
- コンピュータは電気の ON/OFF = 2進数で情報を扱う
- 1ビット = 0 か 1、8ビット = 1バイト
- 16進数は2進数を人間が読みやすくした表現で、4ビット = 1桁

## 確認問題

**Q1.** CPU、メモリ（RAM）、ストレージの違いを「速度」「電源を切った後のデータ保持」の2点から説明してください。

**Q2.** 2進数 `10110100` を10進数に変換してください。

**Q3.** 10進数の `200` を2進数に変換してください。

**Q4.** 16進数 `0xFF` は10進数でいくつですか？

**Q5.** なぜコンピュータは10進数ではなく2進数を内部で使うのですか？

<details>
<summary>解答（自分で考えてから開いてください）</summary>

**A1.**
- CPU: 最も高速だがデータを保持しない（計算専用）
- メモリ（RAM）: 高速だが電源を切るとデータが消える（一時記憶）
- ストレージ: 低速だが電源を切ってもデータが残る（永続記憶）

**A2.**
```
1×128 + 0×64 + 1×32 + 1×16 + 0×8 + 1×4 + 0×2 + 0×1
= 128 + 32 + 16 + 4
= 180
```

**A3.**
```
200 ÷ 2 = 100 余り 0
100 ÷ 2 = 50  余り 0
 50 ÷ 2 = 25  余り 0
 25 ÷ 2 = 12  余り 1
 12 ÷ 2 = 6   余り 0
  6 ÷ 2 = 3   余り 0
  3 ÷ 2 = 1   余り 1
  1 ÷ 2 = 0   余り 1

下から読む: 11001000
```

**A4.** 15×16 + 15×1 = 240 + 15 = 255

**A5.** コンピュータの電子回路は「電気が流れているか/いないか」という2状態しか持てないため。この ON/OFF を 1/0 に対応させた2進数が最も自然な表現です。

</details>
