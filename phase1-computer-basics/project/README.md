# 総仕上げプロジェクト: 学習ログ管理ツール

## 概要

Phase 1 で学んだすべての知識を統合して、**コマンドラインで動く学習ログ管理ツール**を作成します。

このツールはあなた自身が毎日使えるものです。学習の記録をつける習慣とともに、
「自分で作ったツールを自分で使う」という開発者としての第一歩を体験してください。

## このプロジェクトで学ぶこと

- シェルスクリプトの実践的な構成（関数分割・エラーハンドリング）
- ファイルをデータストアとして使う方法
- コマンドの引数解析
- テキストデータの読み書きと集計
- パーミッション管理

## 要件

### 必須機能（Must）

1. **add コマンド**: 学習記録を追加する
   - 引数: 学習内容（文字列）、学習時間（分・数値）
   - 自動で現在の日付を記録する
   - データはテキストファイル（CSV 形式）に保存する

2. **list コマンド**: 記録を一覧表示する
   - ID、日付、内容、学習時間を表示する
   - 合計学習時間を分と時間・分の両方で表示する

3. **stats コマンド**: 統計情報を表示する
   - 総記録数
   - 総学習時間
   - 平均学習時間（1記録あたり）

4. **エラーハンドリング**
   - 引数が不足している場合は使い方を表示する
   - 学習時間に数値以外が渡された場合はエラーを表示する

### 追加機能（Want）

5. **search コマンド**: キーワードで記録を検索する

6. **delete コマンド**: 指定した ID の記録を削除する

7. **today コマンド**: 今日の学習記録と合計時間を表示する

## データ形式

記録は `~/.learning_log/records.csv` に CSV 形式で保存します。

```
1,2024-07-01,Phase 1 Lesson 01 コンピュータの構成要素,60
2,2024-07-02,Phase 1 Lesson 02 OS の役割,75
```

フォーマット: `ID,日付,内容,分数`

## ヒント（詰まったときに見てください）

### データの保存先を確認する

```bash
mkdir -p ~/.learning_log
RECORDS_FILE="$HOME/.learning_log/records.csv"
```

### 次の ID を生成する

```bash
# ファイルが存在して中身がある場合
if [ -s "$RECORDS_FILE" ]; then
    NEXT_ID=$(tail -1 "$RECORDS_FILE" | cut -d',' -f1)
    NEXT_ID=$((NEXT_ID + 1))
else
    NEXT_ID=1
fi
```

### 数値チェック

```bash
# 正規表現で数値かどうか確認
if ! echo "$MINUTES" | grep -qE '^[0-9]+$'; then
    echo "エラー: 学習時間は数値で入力してください"
    exit 1
fi
```

### CSV から特定の列を取り出す

```bash
# 4列目（分数）の合計
TOTAL=$(awk -F',' '{sum += $4} END {print sum}' "$RECORDS_FILE")
```

### 分を時間・分に変換する

```bash
HOURS=$((TOTAL / 60))
MINS=$((TOTAL % 60))
echo "${HOURS} 時間 ${MINS} 分"
```

## 開発手順

### ステップ 1: スターターコードを読む

`starter/learning-log.sh` のスターターコードを読んで、構造を把握してください。

### ステップ 2: `add` コマンドを実装する

まず `add` コマンドだけを実装して動作確認します。

```bash
$ ./learning-log.sh add "テスト学習" 30
```

### ステップ 3: `list` コマンドを実装する

保存されたデータを読み込んで表示できるようにします。

### ステップ 4: `stats` コマンドを実装する

`awk` を使って集計します。

### ステップ 5: 追加機能を実装する

余裕があれば `search`、`delete`、`today` を実装してください。
