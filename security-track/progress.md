## 設計方針(このコースの約束)

1. **実戦重視**: やられ役アプリ(Juice Shop/DVWA)で実際に攻撃し、直す。
2. **理論を丁寧に**: 各攻撃を「なぜそうなるか」原理から。暗記させない。
3. **倫理第一**: 全編で「許可された環境でのみ」を徹底。Lesson 00 で隔離を最初に学ぶ。
4. **本編と同じ文体**: 🌟旅の始まり / 💡コラム(実話・例え話) / 日英併記 / まとめ / 確認問題。
5. **一本の道**: 土台の理論 → Web 攻防 → 基盤 → 実務(攻/防) → キャリア → 総仕上げ。

## 学習の進め方
