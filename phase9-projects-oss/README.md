# Phase 9: 総合プロジェクトと OSS 貢献

## 概要

Phase 9 は、これまでの学習を統合し、実際に世界へ向けて成果を発信するフェーズです。
キャップストーンプロジェクトを通じて「0 から本番稼働まで」を経験し、オープンソースソフトウェア(OSS: Open Source Software)への貢献を通じて実際の開発現場に近い経験を積みます。

このフェーズを修了したとき、あなたは「コードが書けます」ではなく「動いているプロダクトを届けた実績があります」と世界に向けて主張できるエンジニアになっています。

---

## 前提知識

**Phase 8 を修了していること。**

具体的には以下の技術・概念を理解・実践済みであることを前提とします。

- React によるフロントエンド開発
- FastAPI による RESTful API の設計と実装
- PostgreSQL によるデータモデリングと SQL
- Docker / Docker Compose によるコンテナ化
- GitHub Actions による CI/CD パイプラインの構築
- Git によるバージョン管理とブランチ戦略
- 基本的なクラウドデプロイ(AWS / GCP / Heroku 等)

## 修了条件チェックリスト

以下をすべて達成することで Phase 9 修了とします。

### キャップストーンプロジェクト

- [ ] 要件定義書(または Design Doc)を GitHub リポジトリに配置してある
- [ ] フロントエンド(React)、バックエンド(FastAPI)、データベース(PostgreSQL)が Docker Compose で一発起動できる
- [ ] ユーザー認証(サインアップ / ログイン / ログアウト)が動作する
- [ ] コア機能が最低 3 つ実装され、それぞれに E2E テスト(またはインテグレーションテスト)がある
- [ ] GitHub Actions で lint / test / build が自動実行される
- [ ] 本番環境 URL が存在し、インターネットからアクセスできる
- [ ] README.md にスクリーンショットまたはデモ動画リンクが含まれている
- [ ] 評価ルーブリックで「中級」以上のスコアを自己評価できる

### ポートフォリオ

- [ ] GitHub プロフィール README を整備した
- [ ] キャップストーンリポジトリの README が英語で書かれており、デモリンクがある
- [ ] LinkedIn または個人サイトにプロジェクト実績が掲載されている

### OSS 貢献

- [ ] 貢献先リポジトリを 1 つ以上選定し、CONTRIBUTING.md を読んだ
- [ ] good first issue に対して Issue コメントまたは PR を送った
- [ ] PR がオープン状態(マージされなくても可)になっている

### 振り返りと発信

- [ ] 技術ブログ記事(日本語または英語)を 1 本以上公開した
- [ ] Phase 9 で学んだことを 3 つ以上箇条書きで言語化できる

## このフェーズを終えた先

Phase 9 を修了したエンジニアは、次のステップとして以下を検討できます。

- 実際の就職・転職活動(ポートフォリオを武器に)
- OSS メンテナーへの挑戦
- 技術カンファレンスへの登壇応募
- 個人プロダクトの立ち上げ・マネタイズ
- 技術スペシャリスト(SRE、セキュリティ、ML エンジニア等)への深化

世界基準のエンジニアへの道は、このフェーズで「作り、届け、貢献する」ことから始まります。
