# 演習 05: ハッシュテーブル

## Easy

### E5-1: Two Sum

整数配列 `nums` と整数 `target` が与えられます。和が `target` になる 2 つの要素のインデックスを返してください。答えは必ず 1 つ存在します。

**例:**
```
nums = [2, 7, 11, 15], target = 9  → [0, 1]
nums = [3, 2, 4],      target = 6  → [1, 2]
```

**制約:**
- 時間計算量 O(n) で解くこと

---

### E5-2: アナグラムの判定 (Valid Anagram)

文字列 `s` と `t` が与えられます。`t` が `s` のアナグラム(同じ文字を並べ替えたもの)かどうかを判定してください。

**例:**
```
s = "anagram", t = "nagaram"  → True
s = "rat",     t = "car"      → False
```

**制約:**
- `sorted()` を使わずに O(n) で解くこと

---

## Medium

### M5-1: グループアナグラム (Group Anagrams)

文字列配列 `strs` が与えられます。アナグラムをグループにまとめて返してください。

**例:**
```
strs = ["eat","tea","tan","ate","nat","bat"]
→ [["bat"],["nat","tan"],["ate","eat","tea"]]
```

---

### M5-2: 最長連続シーケンス (Longest Consecutive Sequence)

整数配列 `nums` が与えられます。連続する整数シーケンスの最長の長さを O(n) で返してください。

**例:**
```
nums = [100, 4, 200, 1, 3, 2]  → 4  (1, 2, 3, 4)
nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]  → 9
```

**ヒント:** set を使って O(1) で「ある数が配列に含まれるか」を確認します。

---

## Hard

### H5-1: 部分配列の和が k になる個数 (Subarray Sum Equals K)

整数配列 `nums` と整数 `k` が与えられます。合計が `k` になる連続部分配列の数を返してください。

**例:**
```
nums = [1, 1, 1], k = 2  → 2
nums = [1, 2, 3], k = 3  → 2  ([1,2] と [3])
```

**ヒント:** 累積和とハッシュテーブルを組み合わせます。負の数を含む配列にも対応してください。
