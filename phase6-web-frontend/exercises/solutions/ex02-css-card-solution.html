カード 3: 長い説明文

このカードは説明文がとても長くなっています。 それでもレイアウトが崩れず、ボタンが下端に揃うことを確認してください。 CSS Grid の auto-fill と minmax により、 画面幅に応じて列数が自動的に変化するレスポンシブデザインが実現されています。 画像は aspect-ratio で比率を固定しているため、 読み込み前後でレイアウトがずれる CLS も防止できています。
