# 演習 02: 変数・データ型・演算子

## 基本

1. 次の変数を作成し、それぞれの型を `type()` で確認せよ。
   - 整数 `42`
   - 浮動小数点数 `3.14`
   - 文字列 `"hello"`
   - 真偽値 `True`
   - `None`

2. 次の演算の結果を**実行前に**予測し、REPL で確認せよ。
   - `17 // 5`
   - `17 % 5`
   - `-17 // 5`
   - `2 ** 8`
   - `True + True + False`

3. 摂氏温度を華氏に変換するプログラムを書け。
   - 変換式: `F = C * 9/5 + 32`
   - 入力: `celsius = 100`
   - 出力例: `100°C は 212.0°F です`

4. 円の半径から面積と円周を計算するプログラムを書け。
   - π は `3.14159` を使うこと
   - 結果は小数点以下 2 桁で表示すること

## 応用

5. BMI を計算するプログラムを書け。
   - `weight_kg` と `height_m` を変数として定義する
   - BMI = 体重(kg) / 身長(m)^2
   - 判定: 18.5 未満→「低体重」、25 未満→「普通体重」、25 以上→「肥満」

6. 次のコードの `y` の値を実行前に予測し、その理由を説明せよ。

   ```python
   x = 10
   y = x
   x = 20
   print(y)
   ```

7. 数値を文字列に連結しようとして発生するエラーを修正せよ。

   ```python
   score = 95
   message = "あなたの点数は " + score + " 点です"
   print(message)
   ```

## 挑戦

8. 次の操作を行うプログラムを書け。
   - ユーザーから(コードに直接書いてよい)摂氏温度と体重と身長を受け取る
   - 華氏への変換と BMI 計算を同時に行う
   - 結果をきれいにフォーマットして表示する

   「ほぼ等しい」比較をするプログラムを書け。
