## 問題 2: `-17 // 5` が `-4` になる理由

Python の整数除算 `//` は「フロア除算」と呼ばれます。
数学的な「床関数(floor)」— 数直線上で、その数以下の最大の整数 — を返します。

```
-17 / 5 = -3.4
floor(-3.4) = -4  ← -3.4 以下の最大の整数は -4(-3 は -3.4 より大きい)
```

C や Java の整数除算(ゼロ方向への切り捨て)とは異なる点に注意してください。

## 問題 6: 参照モデルの解説

```
x = 10 を実行後:
  x ──────▶ [int: 10]  (id=AAA)

y = x を実行後:
  x ──────▶ [int: 10]  (id=AAA)
  y ──────┘

x = 20 を実行後:
  x ──────▶ [int: 20]  (id=BBB)  ← x の参照先が変わった
  y ──────▶ [int: 10]  (id=AAA)  ← y は変わらない
```

`x = 20` は「x の箱の中身を 20 に書き換える」のではなく、
「x というラベルを新しい整数オブジェクト 20 に貼り直す」操作です。
y は元の 10 を指したまま変わりません。

これがミュータブルなオブジェクト(リストなど)と異なる点です:

```python
a = [1, 2, 3]
b = a         # a と b は同じリストオブジェクトを参照
a.append(4)   # リストオブジェクト自体を変更
print(b)      # [1, 2, 3, 4] ← b も変わる!
```

## 問題 9: 浮動小数点の誤差の原因

コンピュータは数を 2 進数で表現します。
10 進数の `0.1` は 2 進数では `0.000110011...` と無限循環小数になります。
コンピュータはこれを有限ビットで近似するため、わずかな誤差が生じます。

| 値   | 2 進数表現(近似)                |
|------|--------------------------------|
| 0.1  | 0.100000000000000005551... |
| 0.2  | 0.200000000000000011102... |
| 合計 | 0.300000000000000044409... |

`math.isclose(a, b, rel_tol=1e-09, abs_tol=0.0)` は相対誤差で比較します。
金融計算など精度が重要な場面では `decimal.Decimal` を使ってください。
