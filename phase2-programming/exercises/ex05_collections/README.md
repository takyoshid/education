# 演習 05: コレクションと内包表記

## 基本

1. リスト `[3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]` に対して次を行え。
   - 重複を除いた要素数を求める
   - 最も多く出現する要素を求める
   - ソートして逆順に並べる

2. 辞書 `{"Alice": 85, "Bob": 92, "Carol": 78, "Dave": 92}` に対して次を行え。
   - 成績順(降順)に並べた名前のリストを作る
   - 平均点を計算する
   - 最高点の人物を取り出す

3. 次の内包表記を書け。
   - 1 から 20 までの偶数のリスト
   - 文字列リスト `["apple", "banana", "cherry"]` を大文字に変換したリスト
   - 辞書 `{"a": 1, "b": 2, "c": 3}` のキーと値を入れ替えた辞書

## 応用

4. 2 つのリストから辞書を作れ。

   ```python
   keys = ["name", "age", "city"]
   values = ["Alice", 30, "Tokyo"]
   # → {"name": "Alice", "age": 30, "city": "Tokyo"}
   ```

5. 単語のリストを長さごとにグループ分けする辞書を作れ。

   ```python
   words = ["cat", "dog", "elephant", "ant", "bee", "python"]
   # → {3: ["cat", "dog", "bee"], 4: ["ant"], 8: ["elephant"], 6: ["python"]}
   ```

6. 行列の転置(行と列の入れ替え)を内包表記で実装せよ。

   ```python
   matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
   # → [[1, 4, 7], [2, 5, 8], [3, 6, 9]]
   ```

## 挑戦

7. アナグラムのグループ分けをせよ。
   - 同じ文字を並べ替えて作れる単語(アナグラム)をグループにまとめる
   - 入力: `["eat", "tea", "tan", "ate", "nat", "bat"]`
   - 出力: `[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]`

8. カウンターを使わずに、テキスト内の単語の出現頻度を数える辞書を作れ。
   その後、出現頻度 Top 5 を表示せよ。
