# 演習 07: ファイル入出力と例外処理

## 基本

1. 次のテキストを `poem.txt` に書き込み、読み込んで行番号付きで表示せよ。

   ```
   春はあけぼの
   夏は夜
   秋は夕暮れ
   冬はつとめて
   ```

2. `numbers.txt` に 1 から 100 までの整数を 1 行ずつ書き込むプログラムを書け。
   その後、そのファイルを読み込み、合計と平均を計算せよ。

3. 次の例外処理を書け。
   - 存在しないファイルを読もうとしたときのエラーハンドリング
   - エラーが起きても "処理終了" が必ず表示される

## 応用

4. CSV ファイルの操作を実装せよ。
   - 次のデータを `students.csv` に書き込む

     ```
     名前,国語,数学,英語
     Alice,85,92,88
     Bob,72,65,80
     Carol,90,88,95
     ```

   - ファイルを読み込み、各生徒の平均点を計算して追加した列を出力する

5. JSON を使って設定ファイルを読み書きする関数を書け。
   - `load_config(path)`: JSON ファイルを読み込んで辞書を返す。ファイルがなければデフォルト値を返す
   - `save_config(path, config)`: 辞書を JSON ファイルに保存する

6. ディレクトリ内のすべての `.txt` ファイルを読み込み、
   単語の出現頻度をカウントして上位 10 語を表示するプログラムを書け。

## 挑戦

7. 独自例外クラスを定義し、CSV パーサーを実装せよ。
   - `CSVParseError`: CSV の形式が不正
   - `CSVValidationError`: 値の検証に失敗
   - 年齢列は正の整数でなければ `CSVValidationError` を発生させる

8. `pathlib` を使ってファイルのバックアップシステムを作れ。
   - ファイルを上書き保存する前に `.bak` 拡張子でバックアップを作成する
   - バックアップは最大 3 世代保持する(`file.bak.1`, `file.bak.2`, `file.bak.3`)
