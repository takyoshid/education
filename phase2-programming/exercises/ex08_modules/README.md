# 演習 08: モジュールとパッケージ

## 基本

1. 次の構造でパッケージを作り、それぞれのモジュールをインポートして使え。

   ```
   geometry/
   ├── __init__.py
   ├── circle.py    (circle_area, circle_circumference)
   └── rectangle.py (rectangle_area, rectangle_perimeter)
   ```

2. `datetime` モジュールを使って次を実装せよ。
   - 今日の日付を "2024年03月15日(金)" のようにフォーマットして表示
   - 誕生日を入力として受け取り、今日何歳かを計算する

3. `random` モジュールを使ってトランプのデッキをシミュレートせよ。
   - 52 枚のカードをリストで表現する
   - シャッフルして最初の 5 枚を引く

## 応用

4. `collections.Counter` を使って次を実装せよ。
   - テキストファイル内の単語出現頻度を集計する
   - 上位 N 語を返す関数 `top_n_words(text, n)` を書く

5. `argparse` を使って CLI ツールを作れ。
   - ファイル名を引数として受け取る
   - `--lines N` オプションで先頭 N 行を表示する(デフォルト: 10)
   - `--count` オプションを付けると行数だけ表示する

6. `if __name__ == "__main__"` の動作を確認せよ。
   - モジュール `mymath.py` に関数と `__main__` ブロックを書く
   - `python mymath.py` での実行と `import mymath` での動作の違いを確認する

## 挑戦

7. `functools` モジュールの `lru_cache` を使って、フィボナッチ数列を効率的に計算せよ。
   - キャッシュなしの場合とキャッシュありの場合の実行時間を `time` モジュールで計測して比較せよ

8. プラグインシステムを実装せよ。
   - `plugins/` ディレクトリ内の全 `.py` ファイルを動的に読み込む
   - 各プラグインは `run()` 関数を持つとする
   - 全プラグインの `run()` を呼び出すメインスクリプトを書く
