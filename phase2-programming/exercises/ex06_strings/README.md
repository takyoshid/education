# 演習 06: 文字列処理とフォーマット

## 基本

1. 次の文字列操作を行え。
   - `"  Hello, World!  "` の前後の空白を除去せよ
   - `"hello world"` を単語ごとに大文字始まりにせよ
   - `"apple,banana,cherry"` をカンマで分割し、リストにせよ

2. f 文字列を使って次をフォーマットせよ。
   - 商品名: `"Python入門書"`, 価格: `2980`, 数量: `3`
   - 出力: `Python入門書 × 3冊 = 8,940円(税込: 9,834円)`

3. 文字列 `s` を受け取り、次を返す関数を書け。
   - 文字数
   - 大文字の数
   - 小文字の数
   - 数字の数
   - スペースの数

## 応用

4. CSV 形式の文字列をパースして、辞書のリストに変換せよ。

   ```python
   csv_text = """name,age,city
   Alice,30,Tokyo
   Bob,25,Osaka
   Carol,35,Nagoya"""
   # → [{"name": "Alice", "age": "30", "city": "Tokyo"}, ...]
   ```

5. 名前リストを `"Alice, Bob and Carol"` のようにフォーマットする関数を書け。
   - 1 人: `"Alice"`
   - 2 人: `"Alice and Bob"`
   - 3 人以上: `"Alice, Bob and Carol"`

6. テキストの各行を最大 `width` 文字で折り返す関数を書け(単語の途中で切らない)。

## 挑戦

7. 正規表現を使って次を実装せよ。
   - 文字列から日本語の郵便番号(〒123-4567 形式)を全て抽出する関数
   - 文字列内のURLをすべて取得する関数

8. テンプレートエンジンを自作せよ。
   - `"{name}さん、{greeting}！"` のようなテンプレートに辞書を渡して置換する関数
   - キーが存在しない場合は `KeyError` を発生させる
   - `render(template, **kwargs)` というインターフェースにすること
