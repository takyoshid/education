# 演習 03: 条件分岐とループ

## 基本

1. 整数 `n` を受け取り、FizzBuzz を行うプログラムを書け。
   - 3 の倍数なら "Fizz"
   - 5 の倍数なら "Buzz"
   - 15 の倍数なら "FizzBuzz"
   - それ以外は数値をそのまま表示

   1 から 20 まで表示すること。

2. リスト `[10, 3, 7, 1, 9, 4, 6, 8, 2, 5]` の最大値と最小値を、
   `max()` や `min()` を使わずにループで求めよ。

3. `range()` を使って次を出力せよ。
   - 1 から 10 までの合計(55)
   - 1 から 100 までの奇数の合計

4. 九九の表を `for` ループのネストで出力せよ。

## 応用

5. 文字列 `s` が回文(前から読んでも後ろから読んでも同じ)かどうかを判定するプログラムを書け。
   - "racecar" → True
   - "hello" → False
   - "level" → True

6. リスト内の重複する要素を除いた新しいリストを、set を使わずに作成せよ。
   - 入力: `[1, 2, 2, 3, 4, 3, 5]`
   - 出力: `[1, 2, 3, 4, 5]`(順序を保つこと)

7. 数字のリストを受け取り、正の数、負の数、ゼロの個数をそれぞれカウントするプログラムを書け。

## 挑戦

8. `for...else` を使って素数判定関数を書け。
   - `is_prime(n)` は `n` が素数なら `True` を返す

9. コラッツ予想のシミュレーションを書け。
   - n が偶数なら n / 2
   - n が奇数なら 3n + 1
   - これを繰り返すと必ず 1 になる(予想)
   - 任意の正の整数から 1 になるまでのステップ数と数列を出力せよ

10. 2 つのリストを比較し、片方にのみ存在する要素を見つけるプログラムを、
    set を使わずにループで実装せよ。
