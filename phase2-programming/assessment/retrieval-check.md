# Phase 2 Retrieval Check

## 問題バンク

`lessons/` にある全レッスン末尾の「確認問題」を正式な問題バンクとします。問題文をこのファイルへ複製せず、`レッスンファイル名#問題番号`で識別します。

## 実施条件

- 評価者が全レッスンから偏りなく20問を選ぶ
- 各レッスンから最低1問を含め、残りは学習目標の比重に応じて配分する
- 制限時間30分。教材、個人メモ、検索、AIは使用禁止
- 口頭または記述で回答する。追加質問は問題の意味を明確にする場合だけ許可する

受験者と評価者が同一の自習環境では、問題番号を見ずに各レッスンの問題数を数え、日付（YYYYMMDD）をseedにした乱数抽選で選びます。抽選結果は回答開始前に固定します。

## 採点

各問2点、合計40点です。

- 1点: 結論、定義、手順がレッスン本文および「まとめ」と整合する
- 1点: 理由、具体例、適用条件、失敗条件のうち問題が求める要素を説明できる
- 0点: 無回答、主要概念の取り違え、理由を説明できない推測

32点（80%）以上で合格です。採点者はレッスン本文と「まとめ」を採点基準として参照し、単語の完全一致だけで減点しません。

## 記録と再試験

`evidence/phase-2/retrieval-check.md` に次を保存します。

- 実施日時、制限時間、評価者
- 出題した `レッスンファイル名#問題番号`
- 各問の得点と、失点した理由
- 合計点、正答率、再学習するレッスン
- 再試験の場合は前回の記録への参照

再試験は最低48時間空け、前回と同じ問題を1問も使用しません。
