# Phase 2: プログラミング基礎(Python)

## このフェーズの目的

プログラミングの「考え方」を Python を通じて体得することが目的です。
言語の文法を暗記するのではなく、「なぜそう書くのか」「コンピュータの中で何が起きているのか」を
理解しながら進んでください。

Phase 2 を修了したとき、あなたは「コードを書ける人」から「プログラムを設計できる人」への
第一歩を踏み出したことになります。

## 修了条件チェックリスト

以下を**すべて**達成したら Phase 2 修了です。

- [ ] Python の基本データ型(int, float, str, bool, None)とその違いを説明できる
- [ ] ミュータブルとイミュータブルの違いを具体例で説明できる
- [ ] 関数のスコープ(LEGB ルール)を説明できる
- [ ] list / dict / set の使い分けを説明できる
- [ ] 例外処理(try / except / finally)の目的と使い方を説明できる
- [ ] クラスとインスタンスの関係を説明できる
- [ ] 継承とポリモーフィズムを説明できる

### 技術

- [ ] venv を作成し、pip で依存ライブラリを管理できる
- [ ] Python ファイルをモジュールとして import できる
- [ ] pytest でテストを書き、実行できる
- [ ] pdb または VS Code デバッガでブレークポイントを設定できる
- [ ] 型ヒントを付けたコードを書き、mypy で検査できる
- [ ] PEP 8 に準拠したコードを書ける

### 成果物

- [ ] 各レッスンの確認問題に全問回答した
- [ ] 各演習の「基本」問題を全問解いた
- [ ] 各演習の「応用」問題を 80% 以上解いた

## 学習の進め方

1. レッスンを読む前に「今日は何を学ぶか」を声に出して確認する
2. コード例は必ず**自分で打ち込んで**実行する(コピペ禁止)
3. 「確認問題」は紙またはノートに答えを書いてから答え合わせをする
4. 演習は「基本」→「応用」→「挑戦」の順に取り組む
5. 詰まったら solutions を見る前に 30 分粘る

> **成長の鍵**: エラーメッセージを読む習慣を今すぐつけてください。
> エラーは「失敗の通知」ではなく「次に何をすべきかの指示書」です。
