# Phase 2: プログラミング基礎(Python)

## このフェーズの目的

プログラミングの「考え方」を Python を通じて体得することが目的です。
言語の文法を暗記するのではなく、「なぜそう書くのか」「コンピュータの中で何が起きているのか」を
理解しながら進んでください。

Phase 2 を修了したとき、あなたは「コードを書ける人」から「プログラムを設計できる人」への
第一歩を踏み出したことになります。

---

## 🌟 旅の始まりに: 50年続く、小さな儀式

これからあなたが最初に書くプログラムは、ほぼ間違いなく画面に「Hello, World!」と表示するものです。実はこれ、**50年以上続く世界的な儀式**です。

起源は1970年代、ベル研究所のブライアン・カーニハンが書いたプログラミング言語の入門文書とされています(ヒヨコが「Hello, world」と鳴く漫画が頭にあった、と本人は語っています)。1978年の名著『プログラミング言語C』で世界に広まり、以来、新しい言語を学ぶ人類の最初の一歩は、この挨拶と決まっています。

つまり、チューリング賞受賞者も、Google のトップエンジニアも、Linux を作ったリーナスも、**全員があなたと同じ一行から始めた**のです。画面に最初の Hello, World! が表示された瞬間、あなたは世界最大の共同体の一員になります。

その一行は小さい。でも「自分が書いた命令で、機械が動いた」という体験は、何年経っても色褪せない原点です。どうぞ、儀式を楽しんで。

## 学習の進め方

このPhaseから、すべての演習とプロジェクトをGitで管理します。Phase 0で練習した `init / status / add / commit / log` の最小セットを使い、意味のある変更ごとに履歴を残してください。ブランチ、GitHubへの`push`、Pull Request、復旧操作はPhase 3で学びます。また、通常プロジェクトと並行して [Phase横断プロジェクト](../longitudinal-project/) の `v0.2` に着手してください。

通常演習とプロジェクトの後、[Phase 2 実技試験](assessment/)を解答・AIなしで受験します。公開テストへの合格だけでなく、自分で境界値を追加し、保存失敗時の安全性を説明できることが修了条件です。

1. レッスンを読む前に「今日は何を学ぶか」を声に出して確認する
2. コード例は必ず**自分で打ち込んで**実行する(コピペ禁止)
3. 「確認問題」は紙またはノートに答えを書いてから答え合わせをする
4. 演習は「基本」→「応用」→「挑戦」の順に取り組む
5. 詰まったら solutions を見る前に 30 分粘る

> **成長の鍵**: エラーメッセージを読む習慣を今すぐつけてください。
> エラーは「失敗の通知」ではなく「次に何をすべきかの指示書」です。
