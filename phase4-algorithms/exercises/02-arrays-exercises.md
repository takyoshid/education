# 演習 02: 配列とリスト、二分探索

## Easy

### E2-1: 二分探索の実装

ソート済み整数配列 `arr` と整数 `target` が与えられます。`target` が配列に存在すれば `True`、しなければ `False` を返す関数を二分探索で実装してください。`bisect` モジュールは使わないこと。

**例:**
```
arr = [1, 3, 5, 7, 9, 11], target = 7  → True
arr = [1, 3, 5, 7, 9, 11], target = 6  → False
```

---

### E2-2: 配列の回転の確認

整数配列が与えられます。この配列がある配列をローテーション(回転)した結果かどうかを判定してください。

ローテーション例: `[1, 2, 3, 4, 5]` → `[3, 4, 5, 1, 2]`

**例:**
```
arr = [3, 4, 5, 1, 2]  → True
arr = [1, 3, 2, 4, 5]  → False
```

---

## Medium

### M2-1: Search in Rotated Sorted Array

ある整数をソートした配列を、何箇所かローテーション(回転)した配列 `arr` と整数 `target` が与えられます。`target` のインデックスを O(log n) で返してください。存在しなければ `-1` を返してください。

**例:**
```
arr = [4, 5, 6, 7, 0, 1, 2], target = 0  → 4
arr = [4, 5, 6, 7, 0, 1, 2], target = 3  → -1
```

**制約:**
- `arr` には重複がない
- 時間計算量 O(log n) で解くこと

---

### M2-2: Find Peak Element

整数配列 `arr` が与えられます。ピーク要素(隣接する要素より大きい要素)のインデックスを返してください。複数ある場合はどれでも構いません。

O(log n) で解くことを目指してください。

**例:**
```
arr = [1, 2, 3, 1]          → 2
arr = [1, 2, 1, 3, 5, 6, 4] → 5 (または 2)
```

---

## Hard

### H2-1: Median of Two Sorted Arrays

ソート済み整数配列 `arr1` と `arr2` が与えられます。2つの配列をマージしたときの中央値を O(log(m+n)) で求めてください。

**例:**
```
arr1 = [1, 3], arr2 = [2]          → 2.0
arr1 = [1, 2], arr2 = [3, 4]       → 2.5
```

**ヒント:** 二分探索で「どこで分割すれば左半分と右半分が等しくなるか」を探します。
