# Phase 0 実技試験 — 未知の技術課題を調査する

知識の再現は[Retrieval Check](retrieval-check.md)で先に確認します。

## 試験条件

- 制限時間: 90分
- 教材の例題とは異なる、受験者が未経験のツールまたは技術を第三者が指定する
- AIは使用禁止。検索と公式ドキュメントは使用可
- 調査を始める前に、分かっていること、分からないこと、終了条件を書く

## 課題

指定された技術について「何ができるか」を調べ、最小の動作確認を行ってください。インストールや実行が危険な場合は実行せず、安全な代替検証を提案します。

## 必須成果物

- `question.md`: 調査対象、前提、良い質問の形にした課題
- `hypotheses.md`: 最初の仮説を2つ以上と、それぞれを反証できる確認方法
- `research-log.md`: 検索語、参照URL、情報源を採用・却下した理由
- `verification.md`: 再現可能な手順、実行結果、期待との差
- `reflection.md`: 次に調べることと、今回の調査で判断できなかったこと

## 合格条件

- 公式情報を少なくとも1件使い、情報源の発行主体と更新時期を確認している
- 仮説と検証結果を区別し、途中で仮説を更新した記録がある
- 第三者が手順を再実行でき、成功・失敗を判定できる
- 秘密情報の公開や、意味を理解しない管理者権限の使用がない
- [中央の評価ガイド](../../assessment/)に沿った証拠を提出している
