# 演習 05: 環境構築確認演習

## 目的

Lesson 05 で構築した環境が正しく動作することを確認する。
コマンドを実際に実行し、出力を記録することで「動いた証拠」を残す。

---

## 所要時間の目安

30〜60分(環境構築がすでに完了している場合)

---

## 前提

Lesson 05 の手順を完了していること。
完了していない場合は先に Lesson 05 の環境構築を行うこと。

## 演習 5-C: VS Code の動作確認

### 課題

**ステップ1:**
ターミナルで以下を実行してください:

```bash
cd ~/learning-log
code .
```

VS Code が開いたか: はい / いいえ

開かない場合は Lesson 05 の「ターミナルから VS Code を開く設定」を再確認してください。

**ステップ2: VS Code でファイルを作成・編集する**

VS Code の左サイドバーで「新しいファイル」アイコンをクリックし、
`day01.md` という名前のファイルを作成してください。

そのファイルに以下の内容を書いてください:

```
# Day 1 学習記録

## 今日学んだこと

## 詰まった問題と解決方法

## 明日確認したい疑問
```

ファイルを保存(Command+S または Ctrl+S)して、
ターミナルに戻り以下を確認してください:

```bash
ls ~/learning-log
```

`day01.md` がリストに表示されたか: はい / いいえ

**ステップ3: VS Code の機能を確認する**

以下の操作を試し、それぞれ「できた / できなかった」を記録してください。

| 操作 | キーボードショートカット | 結果 |
|---|---|---|
| コマンドパレットを開く | Cmd+Shift+P (Mac) / Ctrl+Shift+P (Win) | |
| ファイルを保存する | Cmd+S (Mac) / Ctrl+S (Win) | |
| ファイルを検索する | Cmd+P (Mac) / Ctrl+P (Win) | |
| ターミナルを開く | Cmd+` (Mac) / Ctrl+` (Win) | |

## 演習 5-D: 日本語化パックのインストール確認

### 課題

VS Code が日本語で表示されているか確認してください。

日本語で表示されているか: はい / いいえ

日本語でない場合:
1. VS Code を開く
2. Cmd+Shift+P (Ctrl+Shift+P) を押してコマンドパレットを開く
3. 「Configure Display Language」と入力して選択
4. 「日本語(ja)」を選択
5. VS Code を再起動する

## 演習 5-E: 総合チェックリスト

以下をすべてチェックしたらフェーズ0の環境構築は完了:

**ターミナル**

- [ ] `git --version` でバージョンが表示される

- [ ] `git init` でリポジトリを初期化できる
- [ ] `git add` → `git commit` の流れでコミットを記録できる
- [ ] `git log --oneline` でコミット履歴を確認できる

**VS Code**
- [ ] VS Code をインストールした

- [ ] ファイルを作成・編集・保存できる
- [ ] VS Code内のターミナル(Cmd+`)を開ける
- [ ] 日本語化パックを適用した

## エラーが出た場合

エラーが出て解決できない場合は、以下の情報を整理して質問してください:

```
【状況】
環境構築の○○の手順でエラーが出た

【問題】
（エラーメッセージ全文）

【試みたこと】
1.
2.

【環境】
- OS: macOS ○.○ / Windows 11
- Gitバージョン: (git --version の出力)
- その他:
```

コマンド実行後に[自己評価ガイド](solutions/sol05-env-check.md)を読み、期待される出力例とトラブル時の確認項目を参照してください。ユーザー名やパス、バージョンによって実際の出力は異なります。
