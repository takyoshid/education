## 目的

Lesson 03 で学んだ「良い質問テンプレート」を実際に使い、

---

## 演習 3-A: 悪い質問を改善する

以下に「悪い質問」の例が3つある。それぞれをLession 03 のテンプレートに従って
「良い質問」に書き直してください。

不足している情報は**想像で補ってよい**。
ここでの目的は「テンプレートを埋める練習」であり、内容の正確さより
「必要な情報が揃っているか」が評価基準だ。

---

### 悪い質問 1

```
「Pythonが動かないです。どうすればいいですか」
```

**改善後の質問:**

```
【状況】


【問題】


【期待していた動作】


【試みたこと】


【環境】


【関連コード】

```

## 演習 3-B: 自分の詰まり経験を質問文にする

### 課題

これまでの学習で「詰まった」「わからなかった」経験を1つ思い出してください。
経験がまだない場合は、「ターミナルでコマンドを実行したら、予期しないエラーが出た」
という状況を想定して書いてください。

テンプレートを使って、その問題について完全な質問文を書いてください。

```
【状況】


【問題】


【期待していた動作】


【試みたこと】
1.
2.
3.

【環境】
- OS:
- 言語バージョン:
- その他:

【関連コード】

```

質問文を書いた後で確認:
- [ ] 問題の状況が具体的に書かれている
- [ ] エラーメッセージの全文または現象が正確に書かれている
- [ ] 試みたことが3つ以上書かれている
- [ ] 質問を読んだ人が、自分のPCで問題を再現できそうか
- [ ] 質問を書く過程で、問題が自己解決しなかったか(したなら、それを記録する)

## 演習 3-D: ラバーダックデバッグの体験

### 課題

実際にラバーダックデバッグを体験するために、以下のコードの問題を
「ラバーダック(または紙/AI)に説明する」形で解説してください。

**問題のある疑似コード:**

```
ユーザーが入力した数値を受け取る
その数値を2倍にする
2倍にした数値が10より大きければ「大きい」と表示する
それ以外は「小さい」と表示する

実行例:
入力: 6
期待: 「大きい」(6×2=12 > 10)
実際: 「小さい」と表示された
```

**ラバーダックへの説明文:**

「えっと、このコードは○○をしていて、○○のはずなのに……」という形で
声に出すように書いてください。

```
（ここに説明文を書く）
```

説明を書き終えた後:
- 問題の原因の仮説を立ててください:
- その仮説をどうやって確認しますか?

## 提出・確認方法

- [ ] 演習 3-A の3つの悪い質問を改善した
- [ ] 演習 3-B で自分の詰まり経験を質問文にした
- [ ] 演習 3-C のフォームを印刷またはコピーして、今週の記録を始めた
- [ ] 演習 3-D でラバーダックデバッグを実施した

回答後に[自己評価ガイド](solutions/sol03-question-writing.md)を読み、第三者が状況を再現できる情報がそろっているか確認してください。質問文の回答例は唯一の正解ではありません。
