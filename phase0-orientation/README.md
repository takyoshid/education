# Phase 0: オリエンテーション — 学習法とエンジニアという職業

## このフェーズの目的

コードを書き始める前に、「どのように学ぶか」「エンジニアとはどういう職業か」を正確に理解する。
学習法の土台を作ることで、その後のすべてのフェーズの効率が劇的に変わる。

---

## 学習目標

このフェーズを終えると、次のことができるようになる。

1. ソフトウェアエンジニアの職種・キャリアパスを説明できる
2. 能動的学習と受動的学習の違いを理解し、能動的学習を実践できる
3. 詰まったときに「15分ルール」で自己解決を試み、それでも解決できなければ適切に質問できる
4. 公式ドキュメントと英語資料を恐れずに読み始めることができる
5. ターミナル、VS Code、基本ツールが導入済みで動作する

---

## 前提知識

なし。パソコンの基本操作(ファイルの作成・削除、ブラウザの使用)ができれば十分。
